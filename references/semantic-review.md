# 🎭 换模型语义评审 agent（semantic-review）

> **存在理由（第一性）**：语义级「AI 味 / 没人味 / 句子对但没意愿读下去」这一层，**同模型自审照不出来**——写的和审的是同一个模型、同一套口味、同一片视野盲区，自审差分信号 ≈ 零（verdict 干净 ≠ 没 AI 味，writing.md §四磨 已实证）。机器正则只逮得住表层指纹（显性套话黑名单 / 半角 / 加粗计数），逮不住语义。**唯一可行的语义层提升路径 = 换一个无本文上下文的不同模型做语义差分**。本契约把这条从「旁注劝导」升级为「可派发、有结构化产出、可被机器验签名」的正式 agent。
>
> 🔴 **这不是机器硬门**（语义无法被正则强制）。它是「异模型冷读」这道**人在环路的纪律关**：产出 `_stutter-list.md`（带签名），排版 preflight 只验「文件存在 + 签名字段在」，不验内容质量——内容价值靠异模型的差异视野，不靠脚本。

---

## 何时派（When）

- **触发时机**：磨稿（writing.md §四磨）完成后、排版（layout / MD→HTML）之前。是 writing.md §四磨 **step 6 冷读外审**的执行载体。
- **autopilot**：高价值篇（深度文 / 主推文 / 选题重）**默认派一轮异模型语义评审**；纯工具速递类可降级为同模型冷读只抓硬错（语义层留空结论但仍产出签名文件）。
- **不重复跑确定性门**：半角标点 → `verify_cjk_punctuation`、断链/漏嵌图 → `verify_publish_assets`、markdown 崩 → `preflight_markdown`。语义评审 agent **专注「只有人/异模型读得出」的语义层**，别碰这些。

---

## 怎么派（由当前宿主控制器调用独立模型）

编排器 = 当前执行 Skill 的宿主控制器（pipeline.py 不启动模型，见 orchestration.md）。控制器调用一个独立审阅模型，**关键是换模型族和新上下文**：

1. **首选：换模型族** —— `model` 参数指定与写作模型**不同族**的模型（写作通常 Opus → 评审派 **Sonnet 4.6**）。不同架构/训练 = 不同视野盲区 = 真差分。
2. **次选（同族不可换时）**：派一个**全新会话的同族模型**，但**严格无本文上下文**（不喂 `_prep-context.md` / 风格路由 / 写作过程），并叠加**对抗式首读读者**人设（"你是第一次读到这篇的陌生读者，挑刺，不被作者意图带跑"）。比同会话自审强，但弱于换族。
3. **兜底**：交作者本人冷读。

> ⚠️ 同模型 + 同会话 = **不算数**（视野盲区完全重合）。签名里必须如实写评审模型，便于事后判断这一轮含金量。

**输入 bundle（喂给 subagent，只给这些 — 保持"无上下文首读"）：**
- `定稿.md` 全文（**唯一正文输入**）
- 本契约的「语义靶子清单」（下方）+「禁区」（别碰确定性门覆盖项）
- **不给**：`_prep-context.md`、风格路由手册、范文、写作过程、作者意图说明——任何会让评审"被作者带跑"的上下文都不给。

## 找什么（语义靶子清单 — 正则抓不到的那层）

逐段扫，专找以下语义级 AI 味（每条 = 一类"机器逮不到、同模型也照不出"的病）：

1. **导游腔 / 元话语**：文章谈论自己（"接下来我们将探讨"/"正如前文所述"/"本文将从三个方面"）、自报结构、自我总结。**含"自我标签"子型**：回指自己某个观点 / 列表项贴标签、让标签替内容干活——"这条最巧妙"/"这才是真正反直觉的地方"/"最狠的是最后一条"，标签一撕、内容其实很空。人类范文几乎 0 处。
2. **材料悬空 / So What 缺位**：核心 H2 没有承重材料，或论点抛出后读者后果仍不清楚。先补材料/收窄主张；事实、动作、原话已经让后果成立时，不要求再补"意味着"。
3. **复述自己 / 说三遍 / 段落无新增**：同一结论换皮说 2-3 遍，或一段没有新增事实、动作、例子、区分、后果。**含每节尾的"划重点 / 小结"复读块**——摘要职能已由导读栏 / 信息图承担，删或并。
4. **金句轰炸 / 节拍器**：加粗口号先于解释、每节都打同一个拍子，把文章变 PPT（参 craft-techniques §金句节拍器禁令）。
5. **升维空转**：动不动"对全人类的意义"/"时代的洪流"，抽象到没有任何具体落点。**含尾部升华 / 动员 / 展望超长段**（"你还在岸上吗"式连写数百字劝进）——尾部升华 ≤1 段，多出的砍（典型形态：结尾"你还不下水吗"式动员连写上千字）。
6. **类比失职**：难懂概念缺少必要落地，或概念已经清楚却硬塞类比；类比只是装饰、不能承重。
7. **细节越界**：精确时间、天气、对话、心理、感官、第一人称亲历没有可见来源；或为了显得真实把约数擅自精确化。不要因为细节少而要求补写虚构细节。
8. **解释尾巴**：动作、物件、原话或比喻已经表达了情绪，后面又补一句抽象解释，把余味说死。
9. **句间引力断裂**：上句尾不留钩子、下句头不接旧信息，每句都对、但读完第一句没意愿读第二句。
10. **稳定语气漂移**：为"反检测"刻意制造的正式度漂移，全篇不像同一个人在稳定说话。
11. **结尾多余 / 假闭环**：删掉最后 1-2 段不损失新信息；或回扣开头时意义没有变化，只是在重复意象、互动或升华。
12. **意愿层总判**：作为首读陌生读者，哪一段你**真的想往下读**、哪一段**眼睛在打滑**？标出打滑段——这是同模型最照不出、最值钱的差分信号。

**同时也抓**（换"无上下文眼睛"才逮得到的）：① 只有人读得出的**硬错**（指代不清/事实矛盾/数字前后打架）；② **连贯断点**（段落跳接、论证链断）；③ **时间线自洽**（2026-07-21 实战固化——把文中所有具体时间/时长/日期/先后关系列出来互查，如「自救 48 小时」装不下「折腾到第三天」、某动作提交时间早于其后续事件；🔴 作者供图里的时间戳/状态是一手事实，正文叙述与供图打架必报）。

> 🔴 **与事实复核的划界**：冷读抓**内部**（指代不清 / 前后数字打架 / 连贯断点）；定稿数字 / 版本 / 价格 / 时间 / 专名与**外部信源**对不对得上，归 [fact-check.md](fact-check.md) 那道门，冷读不重复核外部真伪。两门磨稿后同窗口并行。

## 产出 schema（`_stutter-list.md` — 必带签名）

写入工作目录 `_stutter-list.md`，**必须以签名块开头**（排版 preflight 验签名字段存在；缺签名 = 退化成同模型自审，会被 WARNING 点名）：

```markdown
<!-- semantic-review-signature
评审模型: claude-sonnet-4-6          # 🔴 必填：实际评审用的模型；与写作模型不同才算数
写作模型: claude-opus-4-8
段数: 23                             # 逐段过完的总段数
评审时间: 2026-06-20
verdict: 3 处语义 AI 味 / 1 处连贯断点 / 0 硬错   # 一句话结论；允许"全文无硬错无断点"
-->

## 语义 AI 味（逐条：引原句 + 问题类型 + 一句改法）
1. 原句「……」 → [导游腔] → 删掉自报结构，直接进入第一个具体场景
2. 原句「……」 → [So What 缺位] → 补一句"所以你今晚就能……"
...

## 连贯 / 硬错
1. 第 N 段「……」 → [指代不清] → "它"指代两个对象，明确为 X
...

## 意愿层（首读陌生读者视角）
- 打滑段：第 X 段（一整段都在升维空转，我开始跳读）
- 最想读下去的段：第 Y 段（具体场景把我钩住了）
```

- 允许**空结论**（"全文无硬错、无断点、无语义 AI 味"），但**必须逐段过完 + 文件必须存在 + 签名必须完整**。
- 签名里 `评审模型 == 写作模型` 时，format_layout 冷读门会 WARNING 提示"本轮为同模型自审，语义差分信号弱"。

---

## 回流（修复 → 复验）

- 主控制器按 `_stutter-list.md` 逐处修复定稿；改动大就重跑一轮异模型评审，改动小则修复处前后连读确认。
- `_stutter-list.md` mtime 早于 `定稿.md` 时，排版 preflight 提示"冷读基于旧稿，建议重派"。

---

## 验证清单（这道关"做到位"的判据）

- [ ] `_stutter-list.md` 存在、非空、含完整签名块（排版 preflight 机器验：存在性 + 签名字段）
- [ ] 签名 `评审模型` ≠ `写作模型`（高价值篇；否则 WARNING 留痕，作者知情）
- [ ] 逐段过完（签名 `段数` 与定稿实际段数大致相符）
- [ ] 语义靶子 12 类 + 硬错/连贯 已逐类扫过（允许某类 0 命中）
- [ ] 修复后若改动大，已重派一轮

> 诚实边界（再强调）：以上 checklist 里只有第 1 项是机器验的（format_layout preflight），其余依赖独立语义审阅。本契约的价值在“换了不同视野的模型”，不在正则能完全理解语义。
