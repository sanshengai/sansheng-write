# 封面规则

新文章默认且唯一推荐风格是 `montage-evidence`。历史风格仅用于复刻旧文章，必须由 `article-meta.yaml` 显式声明；自动流程不得随机轮换。

## 固定合同

- 比例 `2.35:1`，长边至少 1000 px。
- 信息来自定稿，不凭空增加人物、数字、Logo 或结论。
- 深炭 `#0E0E10` 统一画布；只允许 profile 主色与纯白作为前景色。
- 左侧 50% 为主标题区，中间 6% 呼吸区，右侧 44% 为内容证据拼贴；保留 8% 微信裁切安全区。
- 标题块总高度上限为画面高度的 22%。
- 主标题优先读取 `article-meta.yaml:lead.line1`，`lead.line2` 是副标题；
  不得把两行做成同字号、同字重的“八个字一坨”，也不得把文章外标题整句重新塞进封面。
- 标题后方使用本篇专属的暗色英文 ghost 层；右侧只允许一个主隐喻物件与 2--3 个次级证据徽章。

### 🔴 字号层级（锚在画布上，不是相对 L1）

**必须给 L1 一个画布级锚点。**只写“L1 是 100% 基准、L2 是它的 55%--65%”不够 --
那套百分比是自我参照的，模型可以把 L1 定成任意大小、整组等比缩掉。2026-07-28
对照四张实拍封面：同一份 prompt 跑出过 L1 占画幅高 12%（第 76/80 篇，主体感强）
和 8%（第 81 篇，主标题比 ghost 还小、画面没有主体）两种结果。

| 元素 | 尺寸 | 颜色 | 说明 |
|---|---|---|---|
| **L1 主标题** | **cap height = 画布高的 12%--14%**，行宽占左区 70%--90% | 纯白，最重字重 | 全画面唯一主体；任何其他高对比文字都不得比它大 |
| L2 副标题 | L1 cap height 的 **58%--64%** | 白 + 落点词主色 | 单行 |
| descriptor 胶囊 | L1 cap height 的 **30%--34%** | 低对比 | 不与标题争 |
| 英文 ghost | L1 cap height 的 **105%--120%** | 近背景暗色，8%--12% 不透明 | **背景纹理，不是标题**；为塞下 ghost 而缩小 L1 是错的 |

⚠️ ghost 的旧值是 145%--155% of L1 -- 那等于**规范自己在要求英文比中文大**，已废止。

### 🔴 主题色落点（只染一处）

- **只在 L2 里染色，只染收尾的 2--5 个字**（语义落点，如「抢老人」「看得见」「一张日历」）。
- **L1 一个字都不染。**它靠字号称王，再染色会把唯一的视觉焦点拆成两个。
- 落点词由 `article-meta.yaml:lead.accent` **显式指定**；不写就让模型自己挑 L2 收尾短语 --
  能出图，但同一批封面的落点会飘（有的染动词、有的染名词）。**新文章一律显式写。**
- 除 profile 主色外禁止任何彩色。第 79 篇把落点染成蓝色，是直接违反品牌色的事故。

### 🔴 字数上限（由字号倒推，不是拍脑袋）

L1 cap height 取 13%（1024×436 画布 ≈ 57 px），左区去掉留白可用宽 ≈ 460 px，
汉字视觉宽 ≈ cap height，故：

- **L1 ≤ 8 个汉字位**（数字与半角字符按 0.5 折算）
- **L2 ≤ 12 个汉字位**

超限就必然被模型缩字号，规范再严也压不住 -- 所以**字数在标题阶段就要卡死**，见 `title.md`。
- 禁止真人、照片拼贴、亮色底、底部标题条和居中海报式大标题。
- 禁止把 `largest` / `extra-black` / `ultra-black` 写进 canonical prompt。
- 默认 `quiet-pill`：低对比副标题胶囊，不使用高饱和霓虹。

## 内容提炼

封面必须从定稿提取：

1. 一句主标题。
2. 可选的一句副标题。
3. 2--4 个可视化事实或物件。
4. 不应出现的文字与元素。

这些值写入 `visual-plan.json.cover`，再由 `compile-visuals` 编译；模型不得直接自由发挥最终 prompt。

## 验收

独立视觉 QA 至少检查：

- 标题与副标题逐字一致。
- 无意外杂字、伪 Logo、乱码。
- 主标题清晰但不过度粗黑。
- L1/L2/descriptor 主次一眼可辨，不得三行等权。
- **L1 必须是全画面视觉主体**：缩略图尺寸下第一眼落在 L1 上。若第一眼先看到英文
  ghost、或 L1 与 L2 看着差不多大，一律判不通过 -- 这是 2026-07-28 前最常见的漏检项
  （第 79、81 篇都是两行等权却过了闸）。
- **主题色只出现在 L2 的落点词上**；L1 染色、两行都染、或出现非品牌色，判不通过。
- 裁切安全，右侧拼贴不抢标题。
- 实际像素符合深色品牌构图，不得以“同批图片风格一致”代替目标风格核验。

封面规则的机器实现位于 `scripts/visual_workflow.py`、`pipeline.py` 和 `visual_qa.py`；本文件不再维护第二套可执行参数。
