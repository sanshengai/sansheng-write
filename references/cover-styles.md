# 封面规则

新文章默认且唯一推荐风格是 `montage-evidence`。历史风格仅用于复刻旧文章，必须由 `article-meta.yaml` 显式声明；自动流程不得随机轮换。

## 固定合同

- 比例 `2.35:1`，长边至少 1000 px。
- 信息来自定稿，不凭空增加人物、数字、Logo 或结论。
- 深炭 `#0E0E10` 统一画布；只允许 profile 主色与纯白作为前景色。
- 左侧 50% 为主标题区，中间 6% 呼吸区，右侧 44% 为内容证据拼贴；保留 8% 微信裁切安全区。
- 标题块总高度上限为画面高度的 20%，允许范围 18%--22%。
- 主标题优先读取 `article-meta.yaml:lead.line1/line2`，不得把文章外标题整句重新塞进封面。
- 标题后方使用本篇专属的暗色英文 ghost 层；右侧只允许一个主隐喻物件与 2--3 个次级证据徽章。
- 禁止真人、照片拼贴、亮色底、底部标题条和居中海报式大标题。
- 禁止把 `largest` / `extra-black` / `ultra-black` 写进 canonical prompt。
- 默认 `quiet-pill`：低对比副标题胶囊，不使用高饱和霓虹。

## 内容提炼

封面必须从定稿提取：

1. 一句主标题。
2. 可选的一句副标题。
3. 2--4 个可视化事实或物件。
4. 不应出现的文字与元素。

这些值写入 `visual-plan.json.cover`，再由 `compile-visuals` 编译；模型不得直接自由发挥最终 prompt。

## 验收

独立视觉 QA 至少检查：

- 标题与副标题逐字一致。
- 无意外杂字、伪 Logo、乱码。
- 主标题清晰但不过度粗黑。
- 裁切安全，右侧拼贴不抢标题。
- 实际像素符合深色品牌构图，不得以“同批图片风格一致”代替目标风格核验。

封面规则的机器实现位于 `scripts/visual_workflow.py`、`pipeline.py` 和 `visual_qa.py`；本文件不再维护第二套可执行参数。
