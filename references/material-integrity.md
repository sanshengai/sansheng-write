# 材料完整性与诚实边界（material-integrity）

> **第一性原则**：人味首先来自一个人掌握、选择和组织过的真实材料，不来自口语词、精确数字或故意制造的毛边。事实不足时，正确动作是补材料、缩论点或缩篇幅，不是把推理、类比和修辞当作新材料反复展开。

## 一、先声明写作模式

- **现实写作（默认）**：人物、事件、产品、研究、教程、评论、复盘等可被读者当成现实陈述的内容。不得虚构精确时间、天气、地点、对话、心理活动、感官细节或亲历身份。
- **虚构写作**：可以创造细节，但要让读者明确知道这是小说、寓言或虚构演绎。
- **混合写作**：事实段与演绎段必须显式分界；不能把演绎写成亲历或新闻事实。

未声明时一律按**现实写作**处理。

## 二、材料与推理分账

**可承重材料**包括：作者真实亲历、可复核的一手资料、具名采访/引语、公开案例、数据、产品实测、研究结果、可重现步骤、能改变判断的反例。

**不算新增材料**：作者态度、同义改写、类比、金句、修辞、情绪、无来源的“有人说”、从同一事实换三种说法。它们可以解释材料，不能冒充材料。

大纲阶段建立一份材料账本：

| ID | 材料摘要 | 来源/位置 | 来源类型 | 能证明什么 | 不能证明什么 | 对应 H2 |
|---|---|---|---|---|---|---|

长篇现实写作中，每个核心 H2 至少映射一个与其主张相配的承重材料。计划篇幅约 1200 字以上时，通常需要约 5 个彼此独立的材料单元作为起步参照，但**结构优先于配额**：一个完整实测可支撑多步教程，五条相邻评论也未必撑得起一篇深度文。

材料应该形成过程或关系，例如“起因 → 选择 → 结果”“旧状态 → 新变量 → 影响”“主张 → 反例 → 边界”，而不是把若干观点并排堆放。

## 三、材料闸门

动笔前逐个 H2 对账：

1. 这一节新增的事实、动作、案例、区分或后果是什么？
2. 它来自哪里，来源类型是什么？
3. 它最多能支撑到哪一级结论？
4. 删掉这一节，读者会少知道什么？

任一核心 H2 无法回答，按顺序处理：

1. 补搜公开事实、数据、案例或反面证据；
2. 只有作者掌握的私域经历/动机/语气缺失时，最多问 3 个具体问题；
3. 仍不足就收窄主张、合并 H2、缩短文章或暂缓；
4. 禁止用更多解释、虚构场景或“升华”把篇幅撑起来。

## 四、来源类型与断言强度

给关键材料标明来源类型：

1. **直接核验事实**：官网、原始文件、实测、原始研究或可重现结果；
2. **当事方自述**：个人/公司/机构对自己的说法，只能写成“其称/其披露”；
3. **第三方转述**：媒体摘要、旁观者回忆、二手引用，明确归属，不升级为亲历事实；
4. **作者推断**：清楚写成“我判断/可能/更像是”，同时交代依据与不确定性；
5. **未知**：无法核验的内容，删掉、改成待核实或明确未知。

尤其分开三件事：

- **先后顺序**：A 发生在 B 之前；
- **因果关系**：A 导致 B，需要排除其他解释；
- **人物动机**：为什么做，除非当事人明确表达，否则只能是推测。

时间相邻不等于因果，行为结果也不自动证明动机。

## 五、细节真实性

- 精确不等于真实。精确数字、时间、天气、对话、感官和心理只有在来源支持时才写。
- 直接引语必须能追溯到录音、文字记录或公开出处；转述就用转述，不把它加引号“合理还原”。
- 没有细节时，优先写已核验的动作、物件、过程、限制或结果；仍没有就省略。
- 作者第一人称亲历只能来自作者提供的经历。不能为了“有人味”生成“我见过”“有读者问我”“前几天我碰到”。
- 一个动作、物件、原话或比喻已经让情绪成立时就停笔，删除“这让我感到……”“这一幕令人……”式解释尾巴。

## 六、逐段信息账本与压缩测试

每段至少推进一项：**事实 / 动作 / 例子 / 区分 / 后果**。承接、情绪和节奏可以单独成短段，但必须改变理解、视角或语气，不能只是复述。

磨稿时做两次测试：

- **新增信息测试**：这段比上一段多交付了什么？答不出就删、并或补材料。
- **三分之一压缩测试**：把这段压到原长约三分之一，如果信息与语气都没损失，就保留短版。

结尾先做删除测试：删掉最后 1-2 段，文章有没有少一个新发现、必要后果、动作或画面？没有就删。只有当开头的意义经过全文后发生变化，才值得回扣开头；不要为了闭环硬回扣、硬互动或硬升华。

## 七、机器能做与不能做

`audit_quant_signals` 只对部分表面风险给**软提示**，不能判断材料是否真实、因果是否成立或段落是否有新信息。语义层仍须由作者/异模型按本文件、`semantic-review.md` 与 `fact-check.md` 审核；软提示不得反过来成为写作配额。
