# 文体专属规则（教程文 / 方法论清单文 / 技术解读配比）

> 🧭 **何时读**：仅当大纲的「文体三选一」标注为**教程文**或**方法论清单文**，或选题属**技术解读类**（AI / 模型 / 工具解读）时才加载。写普通**深度文**用不到本文件——这三套规则与深度文写法截然不同，从 `writing.md` 抽出独立成文以给写作期减负。
>
> 主写作回路（姿态 / 句间引力 / 过程 / 密度 / 磨 / 自检）仍在 [writing.md](writing.md)，本文件只承载文体专属的骨架差异。

---

## 教程文特殊规则

大纲标注为"教程文"时启用，写法和深度文截然不同：

- 开头不讲故事，直接亮结果
- 表格优先于段落，全文至少 3 张表格
- 每段 1-3 句，不超过 100 字
- 步骤可复制：命令、配置、路径可直接复制
- 每 500-800 字设一个截图标记位 `[截图：描述]`
- 结尾不总结，要升维

## 方法论清单文特殊规则

大纲标注为"方法论清单文"时启用（认知科学普及 / 行动建议 / 生活方式建议），骨架和深度文/教程文均不同：

**结构**：N 个小事（标题 N 项数字明示，如「3 个习惯」「5 步法」「7 类陷阱」），每节 4 段闭环：
1. **场景**：一个具体的疑问/痛点/常见情境（不超过 150 字）
2. **原理**：底层机制（认知科学 / 心理学 / 行为经济学概念命名）
3. **做法**：可立即操作的步骤（动词驱动）
4. **收束**：一句话回扣场景，留给读者「我可以试试看」的钩子

**行动语言三件套（与"鸡汤号"区隔的护城河）：**
- **软启动**：① 试一试 / 不妨 / 你可以先 -- 不强推不命令
- **数字范围**：② 每天 15-30 分钟 / 一周 3 次 / 持续 21 天 -- 给可执行边界
- **延迟承诺**：③ 久而久之 / 假以时日 / 慢慢就会 -- 不许诺即时效果

**文献编号 + APA 兜底**（与"鸡汤号"区隔的护城河 / 学术友好）：
- 关键论点后用 `*N` 标号（如「研究显示 *1」）
- 文末统一列 APA 格式参考文献（作者. (年份). 标题. 期刊/出版社）
- 每篇至少 ≥3 条文献，让"行动建议"有学理支撑而非个人主张

**禁忌（写错就变鸡汤）：**
- 「请 X」「你必须 X」「希望大家 X」祈使句 -- 全部降级为「试一试 X / 不妨 X / 你可以 X」软启动
- 「与你共勉」/「我们一起加油」结尾列可选不默认（用了就要克制只 1 处，不要每篇都用）
- 整篇缺细节范围的笼统口号（「养成好习惯」「保持自律」-- 必须落到「每天 15 分钟」「一周 3 次」具体范围）

**适合场景**：认知科学普及 / 心理学行动建议 / 生活方式建议 / 个人成长方法论。**不适合**：时评 / 财经 / 行业分析（用深度文 + 风格路由）/ 技术操作（用教程文）。

## 技术解读文的干货-故事配比

> 适用范围：一切 AI / 模型 / 工具 / 技术解读类选题。技术解读文如果写得太故事性，模型拆解、评测、实操体感差异的描述就会偏少 -- 读者是冲着技术信息来的，全篇是故事会让干货被稀释。本节固化「故事为壳、信息为核」的配比纪律。

1. **故事为壳，信息为核**。选了生活随笔系风格路由（节奏舒缓、白话、自嘲、反常细节锚那一类）时，只借它的节奏、白话、自嘲、反常细节锚，**不借"琐事打底"的内容配比** -- 生活随笔可以全篇是事，写技术必须段段有货。
2. **每个 H2 至少 1 个"可带走信息块"**：数据对照 / 操作清单 / 体感结论 / 避坑提示，形式不限（清单嵌入、对照段、加粗判断句皆可）。连续叙事不超过约 3 段，必须落一次"读者拿到什么"。
3. **发布 / 评测类文章三件套缺一不可**：① 官方数据 + 一句白话解读（读者最关心"相对上一代提升在哪"）；② 实操体感与上代 / 竞品的差异（具体到行为，不是形容词）；③ 读者能直接抄走的行动建议。
4. **滑读自检**：假设读者只看 H2 + 加粗 + 清单滑完全文，能复述出 ≥3 条干货吗？不能 → 配比失衡，回去补信息块，不是补故事。
