# 转 X（Twitter）文章

已定稿并发布公众号后，把整篇搬成 X 文章（Articles）。X 文章是 Premium 功能，只能走登录态浏览器——X API 没有文章接口，改资料接口也只对付费档开放，第三方 SaaS（OpenTweet / Upload-Post / Publora）都只发普通帖，走 cookie 打内部接口的 `bird` 自己就写着发帖会封号。2026-09-19 看完 12 个开源仓（宝玉 / 王树义 / 向阳乔木 / bird / tweet-cli / x-skills / viral-x-posts / x-twitter-growth / x-thread-skill / x-post-creater / social-post / x-user-skill-creator）的结论：不装任何一个，能用的规则并进本 skill；实施记录见 `docs/plans/2026-09-19-X发布链并入计划.md`。

## 入口

```bash
python3 "$SKILL/scripts/x_article.py" <文章目录> --dry-run                       # 只看块序列（有 定稿.x.md 时优先读它）
python3 "$SKILL/scripts/x_article.py" <文章目录>                                 # 建草稿 → 校验 → 预览截图，不发
python3 "$SKILL/scripts/x_article.py" <文章目录> --publish --caption-file dist/x/caption.txt        # 发布前打确认卡
python3 "$SKILL/scripts/x_article.py" <文章目录> --publish --yes --caption-file …                  # 队列里跳过确认
python3 "$SKILL/scripts/x_article.py" <文章目录> --draft-url <草稿URL> --publish --caption-file …   # 不重建，直接校验已有草稿并发
python3 "$SKILL/scripts/x_article.py" <文章目录> --readback                      # 回读互动数据追加到 snapshots.jsonl
```

- Chrome：脚本先探 `--cdp`（默认取 profile 的 `cdp`，缺省 `http://127.0.0.1:9333`），探不到就用 `chrome_profile` 指定的已登录 Chrome user-data-dir 自己拉起（缺省用 baoyu-skills 的共享 profile，带 `--variations-override-country=us`，否则 Chrome 判不出国家时右上角 Gemini 按钮会消失；手动拉起也要带）。跑的时候**别关那个窗口**——09-19 有一次跑到第 5 张图标签页被关掉，脚本随之中断。
- 锁：`dist/x/.lock` 记 pid，同一篇第二个进程直接退出；总时长超过 40 分钟自杀。
- 配置在 profile `brand.yaml` 的 `distribute.channels.x`：`article_url_template`（网站全文，`{code}` = 小写作品编号）、`podcast_show_url` + `podcast_episode_prefix`（小宇宙节目页与单集前缀）、`tail_line`（署名行）、`cdp`、`chrome_profile`；留空的项文末不放。
- 产物 `dist/x/`：压缩/垫边图、`preview-{top,mid,end}.png`、`receipt.json`（draft_url / post_url / images / diffs / account / published_at 带时区 / caption_sha256 / preview）、`snapshots.jsonl`（append-only）、`caption.txt`（说明文字，写法见 [x-caption.md](x-caption.md)）。
- 说明文字：发布前 `check_caption` 本地预检——256 权重字符（中文 ×2）、无 URL 或裸域名、hashtag <2、无互动诱饵，不过直接拒绝，不等发布按钮禁用。
- 确认卡：`--publish` 不带 `--yes` 时打印「账号 / 标题 / 说明 / 图片数 / 链接 / 预览路径」等交互确认；授权只在本次命令有效，不跨会话。

## 内容如何翻译（原味 = 文字零改动、图在原位、层级对应，不是长得一样）

| 定稿.md | X 文章 | 说明 |
|---|---|---|
| `##` / `###` | 标题 / 副标题 | 编辑器只有这两级 |
| `**粗**`、`<mark>` | 粗体 | 无高亮样式 |
| `> 引用` | 一行一个引用块 | 多段引用会被合成一行 |
| ``` 代码块 | 一行一个引用块，首行保留 `[lang]` | 无代码样式；语言标签让读者知道这是段什么 |
| `---` | 「插入 → 分割线」 | 粘贴 `<hr>` 会被忽略 |
| 表格 | 「字段：值」无序列表 | 粘贴 `<table>` 会压成一行，自动化填单元格太脆 |
| 图片 | 原位插入 | EXIF 转正 → 竖图（宽高比 < 3:4）两侧补边缘中位色垫成 3:4（否则 X 居中裁掉上下）→ 长边 ≤2000 → JPEG q85（带透明才留 PNG）；压完仍 >3 MB 拒绝 |
| 图片 alt | 图下斜体一行 | 信息图不加（标题已画在图里）；正文自带图注不重复 |
| 封面 | frontmatter `cover_image/cover/image` → `素材/cover.*` → `素材/hero.*` | 5:2 裁切由 X 做 |
| SANSHENG-SOURCES / 旧版裸 HTML 来源块 | 文末「信息来源」列表 | |
| DEEP READ / 音频卡 / 播客卡 | 丢弃 | 主题曲默认不放（`--theme` 才合成静帧 MP4）；播客不放 |
| 文末 | 「继续阅读」三链接 + 署名行 | 网站全文（`article_url_template` 按作品编号推）、公众号原文（`_website-sync-receipt.json`）、小宇宙单集（有播客且配了 `podcast_show_url` 时到节目页按前缀 + 标题匹配，匹配不到退回节目主页）；缺哪个不放哪个 |

## 发前适配：公众号稿 → X 稿（2026-09-19 作者定，改动写 `定稿.x.md`）

X 的中文读者主要是海外华人、港台读者和翻墙出来的大陆用户：比公众号读者更技术、投资和创业圈浓度高，对大陆平台（企业微信 / 法拍房 / 中考 / 公众号后台）陌生；X 是实时流，几个月前的模型速递今天发等于零，蒸馏、方法论、「一个人 + AI 做出来」的故事是越放越值钱的存货。所以**要适配，不重写**——一个人在两个平台两副面孔，会被截图。改动写在 `<文章目录>/定稿.x.md`，脚本优先读它，`定稿.md`（公众号定稿）不动，两份共用 `素材/`。

1. **时效标注**：开头写明「截至 YYYY-MM」，数字、版本、价格更新到发布当天；旧文里已经不成立的说法必须清掉（不是照抄）。
2. **地域与货币**：人民币标美元；大陆专有词第一次出现给半句解释；「国内能不能打开」改成「中国大陆能否直连」。
3. **国产模型保留**：DeepSeek / Kimi / Qwen 在 X 上热度高，是卖点不是包袱。
4. **尺度一致**：公众号为过审做的软化不用在 X 上补回来，也别为了 X 加料。
5. **删公众号专属段落**：「第一次来这个号」「点星标」「音频卡」「文末公众号引导」一律去掉；文末只留脚本自动接的「继续阅读」。
6. **长度**：超过 8 千字压到 5–6 千；第一段就给结论和数字。
7. **主帖说明文字另写**：按 [x-caption.md](x-caption.md)，不是导读；不带链接、不带裸域名。

**选篇**：不发几个月前的模型发布 / 速递 / 月度盘点、网站功能介绍（导览一篇已覆盖）、绑定大陆平台或已退休工具的、随笔。**节奏**：每天 1–2 篇，同一系列隔天发（近似内容降权）；一天连发多篇只用于补库存。

## 编辑器的坑（2026-09-18/19 实证，脚本已处理）

- **整篇一次粘贴**（合成 ClipboardEvent 带 `text/html`，Draft.js 解析 `<h1>/<strong>/<blockquote>/<ul>/<ol>`），媒体和分割线位置先放 `<p>XIMGPH_n</p>` / `<p>XDIVPH_n</p>` 占位段。**不要逐段贴**：单元素贴进空块会退化成正文块，标题 / 引用块末尾回车新块还继承样式——09-19 三篇整段正文变成大标题就是这么来的。
- **粘贴后等「块数连续两次相同」**再动，不用固定 sleep；占位段数量与文本长度都对上才算贴成功，否则全选清空重贴（3 次）。
- **占位符替换**：点占位段、`End`、「插入 → 媒体 / 分割线」，新块落在占位段正下方；再逐字退格删占位文字，上方是文字块就再退格一次并入上一块，上方是媒体块则退格无效、留一个空块当间隔。`Shift+Home` 在 Mac 上是选到文档开头，别用。
- **自动保存回滚**：改动后状态栏清空约 3 秒才回到「刚刚最后保存」。媒体处理完编辑器会重渲染，未保存的段落会被吞掉，所以插媒体前后、发布前都要等保存落地。
- **校验**：逐块 diff 文本 + 标题/引用/列表块计数 + 空块数（只允许文末 1 个和两个媒体块之间的间隔）+ 占位符残留，任一不符拒绝发布。只比文本抓不住"正文被当成标题"。
- **Articles 权限会突然消失**（2026-09-19 实证：一天内发到第 7 篇时，账号的 Premium+ 掉了——导航里「文章」「Premium+」「SuperGrok」三项消失、`/compose/articles` 与设置里的 Premium 页都 404、个人资料没了认证标；已发的文章仍可读）。判据就是这四条；脚本现在会在列表页 404 时直接失败，发布后抓不到 URL 时也不再把主页首条当成本篇。原因二选一：SuperGrok Heavy 赠送的 Premium+ 绑定失效，或 X 对高频发文 / 自动化的审查——一天 7 篇长文远超正常人手速，节奏规则（每天 1–2 篇）不只是算法考虑。
- 网络瞬断会让 `page.goto` 报 `ERR_CONNECTION_CLOSED` 或编辑器元素消失，队列层重试即可；重跑会先删同名旧草稿。
- 界面文案（撰写 / 发布 / 添加媒体内容 / 正在处理媒体 / 最后保存…）集中在脚本 `UI["zh"]`，X 改文案只改那一处。

## 传播规则（2026-09 核实；X 今年 1 月换成 Grok 排序、8 月 13 日开源 For You 代码）

- 主帖不带任何 URL：带外链的帖子触达打三到五折（源码里没有"有链接就罚"的硬规则，是"点链接"动作权重远低于回复 / 引用 / 关注，人被带走就没机会做别的）；文章卡片本身就是入口。
- 链接放**文章正文末尾**（「继续阅读」）或**回复**里，两处都不影响主帖排序。
- 权重顺序：回复（尤其作者回回复）＞转发＞资料点击后互动＞书签＞停留＞点赞。抑制项：外链、互动诱饵、近似重复、≥2 个 hashtag、全大写、负面语气（情感打分）。
- 一篇一帖，不拆 thread（作者 2026-09-16 定）；同内容不重发（近似重复惩罚），「2–4 周后重发」的说法不采。
- 时段表（美东 / 印度）不抄，按自家 `snapshots.jsonl` 看。

## 发布后 60 分钟（脚本发完会打印这条提醒）

- 前 30–60 分钟决定这条帖的轨迹：守在评论区，**30 分钟内 3 条以上实质回复**触发二次分发；作者回回复权重最高。
- 30 分钟内**不编辑**帖子，编辑会重置分发。
- 回复是内容，不是客套：每天 5–10 条实质回复给体量 2–10 倍的账号，禁「great thread / 学到了」式；回应对方实际内容，不套模板，不杜撰承诺。
- 留言处理默认**批量确认**：自动回只限感谢 / 正面 / 纯表情；出现登录页 / 验证码 / 限流、回复开始重复、短时爆量就停。

## 账号页记分卡（吸自 x-skills profile-optimizer + x-twitter-growth profile_auditor）

| 项 | 判据 |
|---|---|
| 简介 | 帮谁 + 写什么 + 一个证明，≤160 字，结构化分行（每行一个图标一件事），无 hashtag、无 guru/思想者类词、分隔符 ≤2；**不举具体文章当例子**（作者 2026-09-19：例子没有代表性，读者会以为你只会做这个）。四行结构：经历线 → 使命 → 更新节奏 → 哪里找我 |
| 显示名 | 品牌 + 可搜关键词（@ 用户名不可搜） |
| 用户名 | 品牌可读，和其他平台一致 |
| 头像 | 真人；48px 小圆里看对比度；不要大头 |
| 横幅 | 一句价值主张，**不重复简介**；1500×500 |
| 置顶 | 给新关注者的最佳证明帖，≤30 天换一次 |
| 链接 | 只留一个 |
| 两秒测试 | 陌生人看两秒能说出「这人写什么、我为什么关注」 |

抓来的对照样本（宝玉 / 歸藏 / 向阳乔木 / meng shao / yihong0618 / levelsio / simonw / karpathy）共同点：简介 2–3 行、第一行是具体身份、第二行是你能得到什么、第三行放渠道；没有一个堆形容词；横幅要么真人照要么一句 tagline + 品牌图；置顶都是带数字的代表作。

## 数据与复盘

- `--readback` 追加一行到 `dist/x/snapshots.jsonl`：`captured_at / hours_since_publish / maturity（early <6h → day1 → day3 → week1 → month1 → plateau）/ replies / reposts / likes / bookmarks / article_card`。拿不到的字段记 `null`，不写 0。
- **只比同 maturity** 的快照；主看回复 / 转发 / 书签 / 资料点击，点赞权重最低；模式要跨多篇复现才算数，同系列 3 篇 ≠ 3 个样本。
- 复盘按 [skill-review.md](skill-review.md) 的「结果 → 原假设 → 真正看见的信号 → 混淆因素 → 下一轮测试」模板；多个变量同时改的不叫 A/B，列为混淆因素；发布时段先当假设。
- 扑了先问「钩子 / 正文 / 回报哪一段掉人」，爆了问「什么让它落地」；不拿 AI 检测分当验收，报 tells 数。
