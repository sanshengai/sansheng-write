# 转 X（Twitter）文章

已定稿并发布公众号后，把整篇搬成 X 文章（Articles）。X 文章是 Premium 功能，走登录态浏览器，不走 API——X API 没有文章接口，改资料接口也只对付费档开放，第三方 SaaS（OpenTweet / Upload-Post / Publora）都只发普通帖。

## 入口

```bash
python3 "$SKILL/scripts/x_article.py" <文章目录> --dry-run            # 只看块序列
python3 "$SKILL/scripts/x_article.py" <文章目录>                      # 建草稿并校验，不发
python3 "$SKILL/scripts/x_article.py" <文章目录> --publish --caption-file 说明.txt
python3 "$SKILL/scripts/x_article.py" <文章目录> --draft-url <草稿URL> --publish --caption-file 说明.txt
```

前置：用 baoyu 的 Chrome profile 带 `--remote-debugging-port=9333` 启动 Chrome 并已登录 X（子 shell 里 `nohup … &` 拉起，否则随命令结束被杀）。产物落 `<文章目录>/dist/x/`：垫边图、`receipt.json`（草稿 URL / 帖子 URL / 图片数 / diff 数）。

## 内容如何翻译（原味 = 文字零改动、图在原位、层级对应，不是长得一样）

| 定稿.md | X 文章 | 说明 |
|---|---|---|
| `##` / `###` | 标题 / 副标题 | 编辑器只有这两级 |
| `**粗**`、`<mark>` | 粗体 | 无高亮样式 |
| `> 引用`、``` 代码块 | 一行一个引用块 | 多段引用会被合成一行；无代码样式 |
| 表格 | 「字段：值」无序列表 | 粘贴 `<table>` 会压成一行，自动化填单元格太脆 |
| 图片 | 原位插入 | 宽高比 < 3:4 的竖图两侧补边缘中位色垫成 3:4，否则 X 居中裁掉上下 |
| 图片 alt | 图下斜体一行 | 信息图不加（标题已画在图里）；正文自带图注不重复 |
| SANSHENG-SOURCES / 旧版裸 HTML 来源块 | 文末「信息来源」列表 | |
| DEEP READ / 音频卡 / 播客卡 | 丢弃 | 主题曲默认不放（`--theme` 才合成静帧 MP4）；播客不放 |
| 文末 | 网页版全文链接 | 按作品编号推 `https://sanshengai.top/articles/<code>/` |

## 编辑器的坑（2026-09-18/19 实证，脚本已处理）

- **粘贴走合成 ClipboardEvent**（`text/html`），Draft.js 会解析 `<h1>/<strong>/<blockquote>/<ul>`；图片、视频走「插入 → 媒体」真实路径。
- **光标定位**：真实点击末块后 `Cmd+↓`。`End` 只到当前视觉行尾，长段落会把内容贴进段中间。
- **单元素贴进空块会退化**：`<h1>/<h2>/<blockquote>` 单独贴进空正文块不带样式，贴完按工具栏补；标题 / 引用块末尾回车，**新块继承同样式**，不处理就整段正文变大标题、还留一串空标题块——回车后末块不是正文块就用工具栏改回「正文」。
- **自动保存回滚**：改动后状态栏清空约 3 秒才回到「刚刚最后保存」。媒体处理完编辑器会重渲染，未保存的段落会被吞掉，所以插媒体前后、发布前都要等保存落地。
- **校验**：157 个块逐块 diff 文本 + 标题/引用/列表块计数 + 空块数（只允许文末 1 个），任一不符拒绝发布。只比文本抓不住"正文被当成标题"。
- **发布说明文字上限 256 权重字符**（中文按 2 算，约 128 个汉字），超了发布按钮直接禁用。
- 网络瞬断会让 `page.goto` 报 `ERR_CONNECTION_CLOSED` 或编辑器元素消失，队列层重试即可；重跑会先删同名旧草稿。

## 传播规则（2026-09 核实）

- 主帖不带任何 URL：X 推荐算法对带外链的帖子有 30–50% 触达折扣，第三方实测更低；文章卡片本身就是入口。
- 链接放**文章正文末尾**（网站全文、公众号原文、小宇宙播客）或**回复**里，两处都不影响主帖排序。
- 别多个 hashtag、别全大写、别重复发同一内容；负面语气会被情感打分压流。
- 一篇一帖，不拆 thread（作者 2026-09-16 定）。
