# X 主帖说明文字（文章卡片上方那段话）

发 X 文章时，卡片上方可以放一段说明文字，上限 **256 权重字符**（中文、全角标点、表情按 2 算，约 128 个汉字）。信息流里读者先看到的是这段话，不是文章标题，所以它决定"要不要点开"。`x_article.py --caption-file` 发布前会做权重字数与禁项扫描（`check_caption`），不过就不发。

## 分工

| 位置 | 负责回答 | 谁写 |
|---|---|---|
| 公众号导读 | 这篇讲什么 | writing.md 导读栏 |
| 文章标题 | 这篇写给谁（关键词锚点 + 兑现句） | title.md |
| **X 说明文字** | **为什么现在点开** | 本文件 |

三处**不重复同一句**。说明文字不复述标题，也不概括全文。

## 结构（≤128 汉字，2–3 句）

1. **一个由正文主干兑现的判断** —— 和 title.md 的「兑现」判据同源：出候选时必须能指认它落在正文哪一节，且那一节是主干或落点。
2. **一个有指涉的具体数字** —— 奇数精度（29 个、437 MB、4,730 美元），不写「很多 / 几十 / 5k」。没有数字的篇目用一个具体物件或动作代替。
3. **首句独立成立** —— 信息流只露前两行，第一句被单独截出来也得是一句完整的话。
4. **结尾落地** —— 说完就停。不问「你怎么看」，不写「评论区见」，不承诺「后面告诉你」。

优先形态是「第三人称可核实的案例 / 数据点」（2026-07 X 语料里最常胜出的一型），对应 title.md 的具象型；「How I…」式第一人称开头次之，首句不以「我」开头。

## 禁项（`check_caption` 机扫的四条 + 人看的三条）

- URL 和裸域名（`example.com` 这种没写 `https://` 的也算，X 会自动转成 t.co 链接）：主帖带外链触达打三到五折，链接放文章末尾「继续阅读」或回复里；提网站就写品牌名
- hashtag ≥2；严肃题不放表情
- 互动诱饵：点赞 / 转发 / 关注 / 收藏 / 你怎么看 / 评论区见
- 揭示桥与悬念：「结果呢？」「答案是：」「真相是」「没想到」——与 title.md 六条硬禁、anti-ai-filter §五同源
- 表演式真诚开头：「说实话 / 不瞒你说 / 不受欢迎的观点」
- 说明文字承诺的必须是文章主干交付的：说了「三条路都走通」正文就得有三条；钩子和正文不契约，读者点进去掉线，整条被降权
- 不复述标题

## 出候选的流程

1. Agent 按本文件出 **3 条候选**，每条标注「兑现在正文哪一节」和权重字数。
2. 作者盲选（同 writing.md 开头候选盲选的做法）。
3. 选定的写进 `<文章目录>/dist/x/caption.txt`，`x_article.py --publish --caption-file` 读它。

## 范例（已发篇目）

- ✅ 「Mac 和安卓手机的自带日历，不装第三方软件、不花一分钱，能双向同步。iCloud 和微软账号各卡在手机那头；能走通的是 QQ 邮箱和企业微信。」—— 判断 + 两个可核实的结论，首句独立成立。
- ✅ 「2017 年的海信电视：开机广告没了，29 个预装应用停掉，空闲内存 551 MB 涨到 988 MB。全程 Claude Code 通过 ADB 操作，我敲的命令：零。」—— 四个精确数字，结尾落地。
- ❌ 「我用 AI 清理了家里的电视，效果很惊人，你怎么看？」—— 无数字、第一人称开头、互动诱饵、没兑现点。
- ❌ 「结果呢？只有一条路走得通，答案在文里。」—— 揭示桥 + 悬念，正文不契约。
