# 反 AI 写作工具箱（分层 self-check 配方）

> 这一份是本 skill 的「先扫第一层」规则池，从你自建的多份 author compact（放在 `profile/corpus/authors/` 下）蒸馏而来。
> **不是"N 条规则每段都扫"**，而是分 **3 个层级**，按文章类型/段落属性动态生效：
>
> - **A 层 = 无条件铁律**（任何文章/任何段落必扫）：3 条
> - **B 层 = 场景触发铁律**（按段落属性触发）：1 条
> - **C 层 = 高级招式·按需用**（不进硬 self-check，整篇看 1-2 处）：1 条
>
> 加载流程：先过 A 层 3 条 → 看段落属性触发 B 层 → 看你激活的手册风格是否用到 C 层。
> **不出现"所有规则每段都扫"的虚假高分。**

---

## A 层 · 无条件铁律（每段必扫）

### A1. 类比一律用日常 / 街边事，禁学术词

- **通用度**: 高（多份手册共有的高频招式）
- **正例**（原创示范同一技法——把抽象讲成能拍出来的画面）:
  - 不说「系统的冗余设计」，说「家里备两把钥匙，一把藏在楼道花盆底下」
  - 不说「信息不对称」，说「菜市场老板知道今天这条鱼是不是昨天没卖完的，你不知道」
  - 不说「沉没成本」，说「排了两小时队，轮到你了才发现这家菜难吃，可你还是坐下点了一桌」
- **反例**（AI 黑名单类比域）: 「范式 / 引擎 / 灯塔 / 航向 / 齿轮 / 时代浪潮 / 赛道 / 风口」（一律 0 命中）
- **触发条件**: 任何段落都触发
- **实操**:
  - 抽象 3 句内必出 1 个可拍出来的画面
  - 初稿全文完成后统一扫：「哪段有抽象词没接住？」（不边写边逐段检查——写的时候只管把话顺着说完）
  - 比照：能拍成短视频 1 帧画面的类比就保留，纯文绉绉的对仗（"X 之于 Y"）一律重写

---

### A2. 自嘲消毒 / 自我矮化先于观点

- **通用度**: 高（多份手册共有的高频招式）
- **正例**（原创示范——立观点前先把自己矮化）:
  - 「我也不确定是不是只有我一个人这样想。」
  - 「这话我现在说出来自己都脸红，可当年我是真信了。」
  - 「我数学向来不好，下面这笔账你们帮我核一下。」
- **反例**（直接立观点不先矮化）: 「显而易见的是 X」「毋庸置疑的是 Y」「众所周知 Z」 —— 易被读为说教 / 导师腔
- **触发条件**: 有真实自嘲素材、且在立硬观点 / 泼冷水 / 批评 / 翻转读者预期处才用（没真实素材不硬造，表演性自我矮化也是 AI 味）
- **实操**:
  - 立硬观点前一句先承认自己可能错 / 笨 / 弱
  - 用「我懒」「我估计」「我不知道」这类口语句式，不用「鄙人认为」这种半文半白
  - 把自己矮化到读者下面，观点反而立得住

---

### A3. 数字必须配反差，单纯数字堆砌禁（磨稿期定性自检·参见 anti-ai-filter §2.3.5）

- **通用度**: 较高（多数手册命中；不走数据流的手册与本条不冲突）
- **正例**（原创示范——每个数字都接住一个反差锚）:
  - 「三年前这栋楼的月租还是八千，现在两万三，翻了快三倍。」（时间反差）
  - 「一个二十出头的年轻人，手底下管着三百人，一年在路上跑了十二万公里。」（对照反差）
  - 「本来估摸能省一半时间，真上手才发现，只快了十分钟。」（落差反差）
- **反例**（数据列表式堆数字，AI 报告腔 / 年报腔）:
  - 「2025 年市场规模 5000 亿，同比增长 15.3%，渗透率 23%……」（4 个以上数字堆一起且没有反差锚）
  - 「净利润 1.2 亿，毛利率 35%，ROE 18%」（财报数字列表，缺人话）
- **触发条件**: 段落里出现 ≥1 个数字时
- **实操**:
  - 每个数字 token 必须配「时间 / 对照对象 / 落差」之一；无锚即删
  - 反差锚的 3 种范式：
    - **时间反差**: 「X 年 [数字 A]，N 年后 [数字 B]」
    - **对照反差**: 「[身份/年龄] 在 [反常场景] 中，[反常数字]」
    - **落差反差**: 「[期望] 是 X，实际 Y，差 N 倍」
- **怎么验**: 概念同源 `anti-ai-filter.md §2.3.5 反常细节锚`，但 **A3 没有机器自动扫描**——磨稿期靠人工 / agent 逐段定性判断「每个数字 token 有没有接住反差锚」，不存在 preflight 正则兜底（别误以为有机器闸口）

## B 层 · 场景触发铁律（人物段才扫）

### B1. 写人物用动作短语，禁总结性形容词

- **通用度**: 较高（多数手册命中）
- **一类风格跳过本条**: 若你的目标手册走「化名（小李 / 老王）+ 第一人称带场景」路线，靠场景代入而非动作清单，则这类风格**跳过 B1**
- **正例**（原创示范——用物理动作替总结性形容词）:
  - 「他把简历往桌上一推，转身盯着窗外，半天没说话。」
  - 「她一边刷牙一边翻手机里的订单，牙膏沫顺着手腕往下淌。」
  - 「拍了拍我肩膀，把伞往我手里一塞，头也不回走进雨里。」
- **反例**（总结性形容词）:
  - 「他很敬业 / 她很悲痛 / 他求生欲很强 / 她很虚伪 / 他很无奈 / 他很高兴」
  - 「他充满激情地工作」「她依依不舍地告别」「他坚定不移地走下去」（副词 + 动词 + 形容词的三明治）
- **触发条件**（机械可判，两个 token 类型合取检查）:
  - ① 段落出现**具名人称**（真名 / 化名 / 具体身份代号如「小李」「26 岁白领小陈」「某老板」）
  - ② 段落出现**物理动作动词**（走 / 跑 / 伸出 / 拿起 / 按了 / 咬了 / 打开 / 站着 / 端着……）
  - **两者缺一即不触发**
- **不触发示例**（泛指主语 / 抽象动词 / 机构主语，跳过 B1）:
  - 「父母总是给我们寄不该寄的东西」（泛指主语 + 抽象动词）
  - 「老板们必须学会授权」（泛指主语 + 抽象动词）
  - 「中国企业家正面临可持续发展课题」（机构主语）
- **触发示例**（具人 + 物理动词，强扫 B1）:
  - 「小陈对着手机摄像头**伸出舌头**」（具名化名 + 物理动词）
  - 「小林在拍摄现场一直**站着**」（具名 + 物理状态）
- **实操**:
  - 触发后扫整段：所有「他很 X / 她很 X / 他充满 X 地 Y」一律重写成动作
  - 心理描写禁止直说「他害怕 / 他绝望 / 他高兴」，写他做了什么动作让读者自己感受
  - 动作清单参考池：按了 / 端着 / 拿着 / 拍拍 / 调去 / 双手掩面 / 一边 X 一边 Y

## C 层 · 高级招式·按需用（不进硬 self-check）

### C1. 三连排比第三句必拐弯（节奏锤）

- **通用度**: 中（部分手册特有，属节奏锤而非主轴）
- **别和「工整三连」混用**: 有两种三连，用途不同，别当一回事——
  - **工整三连收口**（不拐弯）: 三个词 / 短句对仗，用来重命名或收束。示范：「工具变了。方法变了。连提问的方式都变了。」
  - **拐弯式三连**（本条）: 前两句同结构铺路，第三句拐弯出最锋利的反常具体。
- **别和 `writing.md` 密度法则 6「情绪顶点同构排比·全文限 1 次」混淆**: 那条管的是「全文唯一情绪顶点处、3-6 连工整对仗收口」（内容递进、非第三句拐弯出反常具体）；本 C1 管的是「拐弯式三连节奏锤」。**两类不同技法，配额各自独立**——情绪顶点同构排比全文限 1 次；拐弯式三连整篇 1-2 处。两者可在一篇里并存，不互相挤占名额。
- **正例**（原创示范——拐弯式三连，第三句出最锋利的具体）:
  - 「她不知道这台机器要连轴转多少年，她也不知道自己的工号会被写进哪份报表，她更不知道这台机器最后是『被人从流水线上直接拆下来、当废铁按斤卖掉』的。」（前两句铺路，第三句出最锋利的具体落差）
- **样本实测频次约 35%** —— 不是主轴，是节奏锤
- **使用规则**:
  - 每 2-3 段出现 1 次即可，**过密反像营销号**
  - 整篇 1-2 处足够
  - 三句必须同结构 + 第三句出反常细节 / 具体落差，否则不算
- **不进硬 self-check**:
  - 不强制每段扫这一项
  - LLM 写到合适节奏点主动用即可
  - 写完整篇后回头看「这一篇有没有出现 1-2 处」就行
  - **C 层规则就是工具不是铁律** —— 这是文件名「工具箱」而非「铁律」的根本原因

## 与你的手册 compact 的关系

self-check 流程（从「边写边逐段扫」改为「初稿完成后统一扫」——
写的时候 working memory 里只放 _prep-context §〇 四原则（开篇策略 / 种子原话或知识路径 / 句间引力 / 终审门），
约束在写作期压每个句子 = 句子各自合规、连起来生涩的来源）:

1. 加载 `_prep-context.md`（含本文 A/B/C 层规则 + 你的手册 compact 特有 3-5 招），**读一遍放下**——写初稿时不逐条对照
2. **一气呵成写完初稿**（只管思路连贯 + 句间承接）
3. 初稿完成后，**逐段统一扫 A 层 3 条**（A3 靠人工 / agent 逐段定性判断，无机器兜底）
4. 看段落属性，**触发 B 层**（两个 token 类型合取判定，人物段才扫 B1）
5. **再扫你的手册特有 3-5 招**（如让步反转锤、叙事阀门词独段、长时段对照等——具体取决于你蒸馏进 `profile/corpus/authors/` 的手册）
6. 回头看 **C 层是否激活了 1-2 处**（不强制每段）
7. 任何一处修改若伤语流 / 承接，**以语流为准回退**（终审门凌驾本工具箱一切条目）

**总计 self-check 维度（磨稿期每段约束数）**:

- 最小：A(3) + B(0) + 手册特有(3) = **6**
- 最大：A(3) + B(1) + 手册特有(5) = **9**
- **每段平均 6-9 个独立约束**，不再有同条砸 3 次的虚假高分；且全部发生在**磨稿期**，不占写作期注意力

> **🔴 总注：本文 A/B/C 三层是「磨稿期对照表」，不进写作期 working memory。**
> 写作期只持有 prep 已置顶的三条核心——**种子 + 句间引力 + 终审门**（即 `_prep-context.md §〇` 三原则）——外加每篇至多 1-2 条「本篇最相关」的 compact 招式；A/B/C 全套（含上面 6-9 条/段）一律**写完初稿后磨稿时再对照查**，写的时候不背、不逐句打钩。
> 原因：写作期同时持有 6-9 条/段语义约束 + 整篇范文 + compact 全文，会触发 SKILL.md 点名的 **CSO「摘要在场即跳过正文」失败模式**——规则越多越互相稀释，最后哪条都没真执行。把这套压到磨稿期、写作期只留 3 条最高原则，是「先把话顺着说完、再回头对照修」的根本理由（呼应 _prep-context §〇 + SKILL.md CSO 风险提示）。

## 与 iron-rules.md 的关系

- `iron-rules.md` = 排版 / 格式层硬约束（破折号 `--` 不用全角 / @page margin / 钩子区加粗下限 等）
- 本文 = 写作层分层 self-check 配方（语义 / 节奏 / 姿态）
- 两者互补；A3 与 `anti-ai-filter.md §2.3.5 反常细节锚` 概念同源，但**本文全部条目（含 A3）都是磨稿期人工 / agent 定性判断，无机器自动扫描**——别把 A3 当成有 preflight 兜底的「可机械验」项

## 历史背景（为什么有这份文件）

复审时通过 dry-run 实证发现：

- 多份手册 compact 的「朴实简洁的小动作」各 10 条
- 其中 **4-5 条跨手册 100% 等价复现**（类比 / 自我矮化 / 三连 / 动作短语 / 数字反差）
- LLM 在 self-check 时会出现「虚假高分幻觉」 —— 自评 4-5 项达成，实际只覆盖 3 个独立维度

本文是这次复审的核心产出：
- 抽出跨手册通用部分到本工具箱
- 各手册 compact 只留手册特有招式
- self-check 分层动态生效，避免「同条砸 3 次」
