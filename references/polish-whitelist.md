# 白名单减法磨稿

> **定位**：写完初稿、读出声之后加载。只处理本清单列出的句式。未命中的句子逐字保留。
> **不注入** `_prep-context.md`（写作期 working memory 只留种子 / 句间引力 / 终审门）。
>
> 借鉴 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)（MIT）的方法：可定位触发标记 + 信息守恒。规则按本 skill 口径独立重写，不复制原文。

## 硬边界

1. **白名单**：只能改下面「改写规则」里的形态。没有把握就不动。
2. **信息守恒**：不为人味补姓名、数字、日期、场景、心理、来源；也不删「可能 / 通常 / 在某些情况下」。改完每个实词要能在原文指出处。
3. **不为像人而加料**：禁止为去 AI 味而插入破句、自嘲、口语词、短段落。人味来自材料和判断，不是化妆。
4. **与 compact 冲突时听 compact**：那是目标作者的真写法。例外：不可豁免核（简洁、不把答案藏到文末、不编造）——见 [writing.md §规则冲突优先级](writing.md)。
5. **伤语流即回退**：任何改写让句子磕巴或句间断开，撤销。

## 不作为改写理由

这些看着像 AI 味，单独拿来改会让文章更假：

| 特征 | 为什么不改 |
|---|---|
| 句长 / 段长不够落差 | 不是稳定的人机区分特征 |
| 少用「就 / 很 / 了」 | 方向是补，但补虚词无法验收 |
| 正文问句、设问、问句小标题 | 人类用得更多；删了更不像人写 |
| 句内同构排比 | 只处理**相邻句**同一骨架（见规则 3） |
| 比喻本身 | 只处理理想化职业人格喻体（规则 7） |
| 正文里的「首先…其次」 | 只管小标题编号（已有排版门） |

## 改写规则

命中则做最小改动。机器软门（warning、不阻塞）见 `contracts._BLACKLIST_SOFT`；硬门仍是原 B-主门 / 导游腔。

### 1. 翻案腔

先立一个读者并没有的误解再推翻：「不是…而是…」「看似…其实…」「你以为…其实…」「表面是 X，背后是 Y」。

改法：直接从正面下判断。材料里真有「从误解走到修正」才允许写自我修正，且不套固定公式。

手册招式（如和菜头「这不是 A，叫做 B」）若在 compact opt-out 里登记为 DNA，放行。

标题侧仍走 `title.md` 揭穿式家族硬门。

### 2. 顿号罗列过密

一个分句里两个以上顿号、三项以上同构并列。能概括就概括；必须保留时打散其中一项的句法。不动 Markdown 列表。

### 3. 相邻句结构同款

连续两句逗号数量、成分顺序、长度接近。打散其中一句。清单式步骤、对话、有意排比不改。

### 4. 破折号当揭晓

非虚构里用破折号制造停顿后的揭晓或塞没必要的补充。改成完整句子，或改用逗号 / 句号。给读者的文字里破折号本 skill 统一 `--`（铁律，硬门另拦全角）。

### 5. 冒号空转

- 提示语引出：「一句话总结：」「核心是：」「关键在于：」——提示语不承担信息就删，直接写内容。
- 空转句引出列表：一行以冒号结尾、下一行是列表、删掉该行信息不减。把该行写成有内容的判断，或删掉让列表接上文。

引出人物引语、小标题冒号、列表项内部冒号不改。

### 6. 序数词当小标题

连续三个以上小标题以「一、二、三」或「第一、第二」开头。删编号、保留原文字。Markdown 有序列表、法规条目交叉引用不改。排版层本就禁止 H3 手写编号。

### 7. 理想化职业人格喻体

「像一位智慧的导师」「永不疲倦的初级审查员」这类带褒义修饰的职业人格。改成这东西实际做了什么，或改用具体的人（「像一个老师傅」可留）。本条**不进机器门**。

### 8. 概括盖掉已有数字

同段已有具体数值 / 时间，却用「显著提升」「大幅增长」「效率的提升」盖住。把已有具体值提到概括词位置。原文没数据时只恢复动词，不许编数字。

与 So What 的分界：后果还没出现时可以补一层「对谁意味着什么」；**与上一句同义的「这意味着」删掉**（见规则 10）。

### 9. 禁用起手式（元话语）

段首 / 句首「说白了，」「说穿了，」「先说结论：」。删掉后直接给判断。

**不是禁判断前置。** 结论先行仍要做。卡兹克句中转译「流体智力，说白了就是悟性」是 DNA，放行——机器硬门只锚**句首**（`_META_DISCOURSE_HARD`）。

### 10. 五种翻译腔

只处理这五种。其余即使读着像译文也保留。

| 形态 | 改法 |
|---|---|
| 中心名词前修饰超过十五字，或「的」连用两个以上 | 拆成两个分句 |
| 「当…时，」前置时间从句 | 删「当」「时」，让从句做前一分句 |
| 「对于…来说 / 就…而言 / 关于…」且后句已以该对象为主语 | 把对象放到主语位置 |
| 句首「然而 / 因此 / 此外 / 与此同时 / 总而言之」连续领段 | 挪到主语后，或换成「不过 / 其实 / 也」 |
| 「这意味着 / 这表明 / 这说明 / 换句话说」且与前句同义 | 并入前句或删提示语 |

「这意味着」后面若真推出了前句没有的后果，按 So What 保留。

### 11. 段首零回指评论

非首段以「听起来 / 看起来 / 值得注意的是 / 更重要的是 / 关键在于 / 问题在于 / 不难看出」起句，且没有「这 / 那 / 其 / 上述」。补一个回指词，多数情况加「这」即可。

与导游腔硬门交叉：「听起来有点抽象」仍走 `_META_DISCOURSE_HARD`。本条管的是缺回指的评论起段。
