## 故事方法论（源自《写作是门手艺》）

故事的极简定义：**"出事了！"** 打破读者平静认知的一切叙述。

**张力三要素（至少用一个）：**
- **冲突**：向相反方向运动的力量碰撞（不必惊天动地，小事也行）
- **对比**：截然相反的特性并排（重与轻、多与少、积极与冷漠）
- **矛盾**：与读者期望背道而驰

**马奇三原则（故事质量检验）：**
- 详尽到足以让人**感兴趣**
- 简单到足以让人**理解**
- 可信到足以让人**接受**

故事服务于观点，不是为了讲故事而讲故事。全文主旨能用一句有张力的话概括出来。

## 开篇技法库（八选一）

> 🔴 **故事钩子分级**：下列含故事 / 场景的技法（A/B/C/D/H），素材**优先真实亲历，虚构演绎慎用**（用前须能说清"非虚构不可"的理由，纯为钩子而编 = 违 [anti-ai-filter.md §六 不编造](anti-ai-filter.md)）。**资讯 / 成果类开篇禁用故事钩子**，走直入或 I 式成果直入（见 [outline.md 步骤 3.5](outline.md)）。

**A. 悬念+故事引入（案例驱动型）**
先抛悬念问题 → "我先给你讲个故事" → 加粗场景描写

**B. 日常发现切入（观点输出型）**
"最近我发现""前几天碰到一个事" → 一句话锁定微观体验

**C. 反差/荒诞制造（行业分析型）**
严肃词开头，落到意想不到的日常话题。一重一轻

**D. 痛点共鸣切入（实用指南型）**
直击读者具体困境 → "你有没有这种感觉" → 一句话点破痛点本质

<!-- 跨路由技法新增 2 类 -->

**G. 反直觉换位设问（财经/认知/AI 类）** ⭐ 高频命中的强开篇式
"如果让你和 [极端对象] 互换 [属性], 你换不换?" → 把读者拉进极端假设场景, 用读者本能反应翻转出原理。
深度详读你为该风格自建的语料手册（`profile/corpus/authors/<name>.compact.md`）。

**H. 痛点共情 → 自建工具 → 5 段叙事公式（个人探索/教程类）** ⭐ 个人探索叙事主路径
"为了解决 [我的困扰], 我做了 [工具/方法], 并打算 [反差利他, 如免费开放]" → 启动 5 段叙事 (痛点→探索→瓶颈反常细节→觉醒减法→利他升华)。
深度详读你为该风格自建的语料手册中的 "5 段叙事公式"。
- 🔴 **仅限深度启发类的个人探索叙事**：自研工具 / 网页 / 成果介绍文（"我做了个 X" 给读者用）禁用本式的成果压轴，改走下方 **I 式成果直入**（成果压轴正是焦虑铺陈被打回的病根）。冲突时以 [outline.md 步骤 3.5 成果类](outline.md) 分流结果为准。

<!-- meta-audit M10：新增 E 类「读者来信式开篇」 -->
**E. 读者来信式开篇（共情代入型）**
借第三方代入读者，姿态比 D 更温和。模板："经常有读者问我：[问题]？怎么办？" / "经常有人问这么一个问题：[问题]……" → 顺势承接给方法
- 与 D 类区别：D 直接戳读者痛点，E 借"另一个人"做缓冲，读者更愿意跟着往下读
- 示例：「经常有读者问我：我照着教程把 AI 助手配好了，可一到真要它干活就卡壳，是漏了哪一步？」——先替读者把那句难堪的话说出口，再顺势给排查清单
- 适用：方法论清单文 / 互动型文章 / 心理/成长类深度文

<!-- meta-audit I28：新增 F 类「自爆角度型开篇」（通用横向技法之一） -->
**F. 自爆角度型开篇（写作动机暴露型）**
作者主动承认"我在写文章"/"我也不知道为啥要写这个"/"今天没别的选题"——通过坦白写作动机消解距离
- 与 B/E 区别：B 是叙述者腔，E 是读者代入，F 是元写作姿态，自承"在炒选题"
- 示例：「今天没什么非写不可的选题，那就聊聊我昨晚一口气删掉的三个 AI 插件。」 / 「先说清楚：这篇没提纲，我边写边想，你就当看我在草稿纸上涂。」
- 适用：评论型文章 / 表达独立判断力 / 反"流量推送"姿态

<!-- I 类「成果直入型」（成果/实作类首选） -->
**I. 成果直入型（成果 / 实作类首选）**
第一句亮成果，不铺垫、不设悬念：「我做了个 X。」/「先给结果，再讲过程。」→ 下一句一话说清它能干什么 → 紧跟入口（网址 / 下载）+ 一个真实产出示例（截图 / 报告 / 实测案例）→ ≤4 段给全文路线图（「带你看三件事：它长什么样 / 我为什么做 / 你怎么用」）。
- **与 H 式的分野**：H 式（痛点共情 → 成果压轴）是深度启发类的个人探索叙事；I 式把成果甩到第一屏，「为什么做 / 制作背景 / 焦虑数据」降级到成果之后。**自研工具 / 网页 / skill / 成果介绍文一律走 I 式、禁用 H 式**。冲突时以 [outline.md 步骤 3.5 成果类](outline.md) 分流结果裁决。
- 示例：一篇"我做了个 AI 风险评测网页"开篇「先给结果，再讲过程。我做了个网页，专门干一件事：输入你的工作，它算你被 AI 取代的概率。网址在这……」；另一篇"我做了个 GitHub 项目精选页"开篇「我在自己的网站上做了一个页面，专门精选好用的 GitHub 项目。……这篇不绕弯子，也不设什么悬念，就平铺直叙地带你看三件事。」
- 适用：自研工具 / 网页 / skill / 成果介绍、实测记录、N 款横评

### 闭环母题（climax 前回收开头钩子句）⭐ 长文 / 长视频招牌

**结构**: 开头钩子的 N 句 (3-6 句) 在 climax 前**一字不差**回收一次, 给观众"圆画完了"的爽感。

**示例** (一支 18 分钟的深度解说视频):
```
[00:00-00:11] 开头钩子 6 句:
  所有人都在抢着接大模型 / 以为这是一场谁的算力更强的比赛 / 没人回头看那根被烧掉的电费单 / 决定生死的从来不是模型多聪明 / 是它每答一次话要烧掉多少钱 / 这笔账，比参数大

[14:46-14:57] climax 前回收同 6 句:
  (一字不差重复)

[14:57-18:33] 第三幕揭真相 (答案 = 谁先把单次推理成本压到盈亏线以下) + 诗意金句收尾
```

**为什么有效**: 观众看了 14 分钟算力与融资的角力, 听到这 6 句重复出现, 立即知道"答案要给了"。比单纯"接下来我揭示真相"高级 N 倍。

**适用**: ≥ 3000 字深度文 / ≥ 5 分钟视频。短文用闭环母题反而显刻意。

**反例**: ❌ 改用近义词 / 部分回收 (失去仪式感) / ❌ 短文 (没有铺垫积累, 回收没爆点)

### 原章节

- **段落长短不均：** 有些段落只有一句话，有些 3-5 句展开。绝不要每段都差不多长
- **句式多变：** 反问句、独立短句、不完整句、设问句；长短句交错
- **拒绝套路过渡：** 用场景切换、问题引入、情绪转折自然衔接

## 节奏控制

- **设问驱动：** 设问用在真转折 / 真困惑处推进论证；**不按字数配额插入**（机械的"每 300-500 字来一句怎么办"是自问自答节拍器，占行数不增信息，见 [anti-ai-filter.md 重定向第 6 条](anti-ai-filter.md)）
- **"锤子"式收束：** 叙述 3-5 句后，用一个**加粗单句成段**敲下结论
- **长短段交替：** 叙述段和单句段交替。绝不允许连续三段以上长度相近

## 过渡技法

- **设问过渡：** 问题结束上一段，回答开启下一段
- **场景切换：** "我再讲个故事"直接跳转
- **让步反转：** 先"可以理解"，再"但"掀翻
- **评论句桥接：** "这不是技术问题，这是商业问题。"

<!-- meta-audit M6：新增「跨界喻体过桥」 -->
### 跨界喻体过桥

类比域**避开行业话术**，优先便利贴 / 收音机旋钮 / 火车站黄牛 / 便当盒 / 串联并联 / 全科 vs 专科医生 / 烈马+马具 等远域物件。**远域类比法则**：想讲清一个抽象概念时，优先用「就像 [日常物]」的远域类比。**有就用、不凑配额**（🔴 不设「每篇必带 ≥2 处」硬配额 -- 为凑数而加的类比不增信息，正是"配额化多样性=新公式化"）。

- **日常物喻体**：「大模型的上下文窗口，就像你桌上那张便利贴——写满了，最早那行字就被你自己撕掉了。」（远域：便利贴，讲清"上下文有限、旧信息被挤出"）
- **物理喻体**：「调参数像给老式收音机拧旋钮：往左噪音，往右也噪音，能出清楚人声的就中间那一丝。」
- **生活场景喻体**：「两个 AI 抢着回答同一个问题，像春运火车站里两个黄牛喊住同一个乘客。」
- **生理喻体**（替道德判词）：不写「这行日志令人担忧」，写「看到那行日志时，我后颈一凉」——用身体反应代替评判词

**自检：** 全篇类比若全在本行业内部（家装文里只用建材打比方）→ 说明有概念没讲透，**考虑换个远域类比、或直接补数据 / 案例**（哪里没讲清补哪里，不是为凑"跨界"硬换）。

<!-- meta-audit M9：新增「岔题宣告 + 锚回」长文专用过渡 -->
### 岔题宣告 + 锚回（≥4000 字长文专用）

主线外深挖一段必须**显式宣告**而非无缝过渡。比"水到渠成"更让读者安心——读者知道"我在岔题"，不会迷路。

- **明示岔开**：「这条支线值得单说两句，主线先按下不表」「这里先岔开一下，让那台服务器再多转一会儿」——读者立刻知道"作者在有意绕路"
- **明示回归**：「好，岔得够远了，我们把话头拉回那台过热的服务器」——硬回归句，读者立刻知道"主线回来了"

**适用：** 章节漫步式书评 / 资深读者长文。≤3000 字短文不需要，无缝过渡即可。**🔴 资讯 / 成果 / 评测类不适用**（这类要不绕弯子、直给干货，岔题 = 读者要干货时被打断，见 [outline.md 步骤 3.5](outline.md)）。

<!-- meta-audit M5：新增「自嘲缓冲 / 自轻消解」（开篇/过渡/收尾通用） -->
### 自嘲缓冲 / 自轻消解（开篇 / 过渡 / 收尾通用）

**注**：此技法可作开篇软着陆、过渡消毒、收尾反向获力三种位置使用。AI 不会自然产生，必须显式 prompt「这里插一句自嘲」。

三种典型用法：
- **批判前的软着陆**：先自认一句再评别人，避免居高临下——「我自己也踩过这坑：上个月还在群里吹这功能多好用，回头就被它坑了一次。」
- **平视消毒**：把自己降级到庸人姿态——「说这话时我正瘫在沙发上，一边吐槽别人不自律，一边第五次点开外卖软件。」
- **结论反向获力**：自报庸人家门，反而让结论更服人——「我承认我又懒又抠：既想让 AI 全自动，又不肯多花一分钱额度；可正是这种人，最能试出一个工具的真底线。」

**自检：** 自嘲**只在有真实素材、且能自然软着陆时用** -- 立硬观点 / 泼冷水前若手上有一句真实的自我调侃，先自贬一句更服人；**没有就不用，绝不为凑"人味"硬插一句自嘲**（表演性自我矮化和刷特征一样是 AI 味，见 [anti-ai-filter.md 重定向第 6 条](anti-ai-filter.md)）。

## 论证技法

<!-- meta-audit I32：「思想 vs 知识」二分法（顶部原则） -->
> **顶部原则（本 skill 采纳）：** 读者要的是**思想**不是**知识**——读者最后想带走的，不是能拿去吹的段子、也不是跟你一起站的队，而是"我下次能不能也这么想一遍"。一切论证手法都服务于"让读者升级看世界的方式"，而非"卖弄你懂得多"。卖弄知识 = 翻墙搜个英文资料显摆，把读者当观众；给思想 = 把读者拉到你身边一起想清楚。

- **树形论证（核心）：** 任何核心观点（树干）抛出后，必须紧跟理由（树枝）和具体证据（树叶）。缺理由的观点是空喊，缺证据的理由是空想

<!-- meta-audit M1：新增「跨文本征引 / 学者引文压阵」 -->
- **跨文本征引 / 学者引文压阵：** 写沉重话题、面对资深读者、评论型文章时，借学者+作品+场景作思维经验插槽。每条引用须符合 writing.md §8.2「KOL 原话引用 + 利益立场标注」。**四种用法：**
  - **反例支撑**：观点抛出后用学者反例对冲，避免一边倒
  - **同行复现**：另一位学者也得过同样结论 → 不是孤证
  - **历史镜像**：当下问题在更早的语境里出现过 → 借古鉴今
  - **留言代言**：引用读者/同行原话替自己说出最不忍说的那句
  - 示例：写技术伦理评论时，交叉引两位立场相反的学者原话对冲；写行业变迁时，连引三五位不同年代亲历者的判断作思维插槽
  - **标志性场景**：写社会结构议题 / 智识杂文 / 书评，**禁忌**：硬塞名人名言充门面

<!-- meta-audit M2：新增「内置反对者自辩」（让步反转的强化版） -->
- **内置反对者自辩：** 在亮观点前**先让对立方说出最强论据**（不是稻草人版本），让步后承认对方有理但仍坚持自己。比让步反转更彻底——让步反转只是"先认一句再翻"，自辩是"把反方武装到牙齿再翻"。
  - **标志句**：「我能理解……但是」三连 / 「换位想，他也不是无理」
  - **三种收束形态**：
    - **温和推翻型**：让步后温和推翻（"我能理解"三遍 → 翻盘）
    - **承认坚持型**：让步后承认反方有理但仍站原立场（"我承认……但是"——承认反方有理，自己仍不退）
    - **框架切换型**：不直接否定，而是换一个维度看同一件事
  - **自检**：写完一段论证回头看，反方观点是不是被你写成弱智版本？是 → 重写反方，让它强到你自己都犹豫为止

<!-- meta-audit M4：新增「反常细节锚 / 物件做证据」 -->
- **反常细节锚 / 物件做证据：** 关键人物/事件出现时，给一个**反常的精确数字+具体动作**，让物件自身承担论证。比形容词强 10 倍。
  - **标准**：读者一周后还能复述这个细节 → 锚成功
  - **示例 1**：「他把三年的对话记录导出来，47 万条，压缩包 1.2 个 G，'删是舍不得删的，可我一条都没再打开过'。这 47 万条，全是深夜发的。」——"47 万条"精确数字、"导出来"具体动作、"全是深夜发的"独立成段冷反转，3 行字立住一个人
  - **示例 2**：不写"他很紧张"，写"他反复刷新那个还在转圈的部署页面，刷了十几次"——用动作替代情绪形容词
  - **物件单独承担论证**：一台顶配显卡 / 半年没交的电费单 / 桌角那本翻烂的 API 文档——物件自带经济与处境信息，不需要作者解释
  - **禁忌**：用"很多""一些""大约"这种泛化词替代精确数字 → 锚失败

<!-- meta-audit I26：新增「重新定义法 / 现象命名」 -->
- **重新定义法 / 现象命名：** 给观察到的现象起一个**新名字**，让读者从"看不见"变成"一眼认出"。比解释三段话更高效。
  - **讽刺命名型**：用带反讽的大词包小事，名字本身就是论证——比如把"装了一堆没人用的 AI 功能"叫「功能仓鼠症」
  - **学理小名词型**：给松散现象一个像术语的小名字，读者获得新的认知工具——比如把"因为已经付过费所以硬用下去"叫「沉没额度依赖」
  - **自检**：通篇有没有 1 个你自创的名词？没有 → 这篇还停在"复述已有概念"，没产出原创洞见

<!-- meta-audit I27：新增「顺水推舟归谬」 -->
- **顺水推舟归谬：** 不直接反驳对方观点，而是**沿对方逻辑往下推一步**，让结论自动荒诞。
  - **示例**（假想评"某平台要求 AI 生成内容必须逐条人工审核"）：「这规矩我举双手赞成，干脆再彻底一点——每条评论也配一个审核员，每个审核员背后再配一个审核审核员的人，就业问题一并解决了。」——不骂规定荒唐，骂它"假装能执行"
  - **要诀**：归谬的"推一步"必须是对方逻辑的**自然延伸**，不是你硬塞的反例。否则读者会反弹——"对方又没这么说"
  - **适用**：评论型文章 / 时事点评 / 反"政治正确"姿态

- **防守反击：** 每篇文章至少设置一次虚拟质疑（"这时候你可能会问……""但等一下——"），提前预判读者疑虑并给出回应。不处理反面=论证有盲区
- **类比优先：** 每个抽象概念 2 句话内跟一个生活化类比，跨领域取喻。好类比的标准：去掉它文章会塌（承重）、往下挖一层还像（多层）、不需要解释就能看懂（自明）
- **故事用对话体：** "他问我""我说"推进叙事
- **数据只做锤子：** 一两个关键数字点到为止，不堆砌
- **"现象→本质→判断"三步法：** 干净利落，不兜圈子

### 论断五分类（源自《写作是门手艺》第五篇）

每抛出一个论断前，先对自己说清楚它是哪一类——不同类需要不同强度的证据。

| 类型 | 在说什么 | 典型信号词 | 需要的证据 |
|------|---------|----------|----------|
| **事实论断** | 客观发生过/正在发生 | "2025 年 Q1 出货 1800 万台" | 可追溯的权威数据源 |
| **定义论断** | 某事应该如何命名/归类 | "这不是智能家居，这是伪联网家电" | 论证为什么旧定义不够用 |
| **因果论断** | A 导致 B | "正是这条新规让品牌被迫下架" | 排除其他解释 + 时间序列对得上 |
| **价值论断** | A 好/坏/值得/不值得 | "这个设计反人类" | 评判标准须先亮出来 |
| **预测论断** | 未来会如何 | "三年内这类产品会消失一半" | 标明依据的趋势 + 给出不确定度；**空泛预测改写成可证伪句**（"会成为下一个重要叙事"→"X 2027 年前超过 Y"，带时间 / 数字才算真预测）|

**操作法：** 全文最多承担 1-2 个预测论断；价值论断必须先铺垫标准；因果论断必须回应"还有没有别的解释"。

### 证据四评估（源自《写作是门手艺》第五篇）

引用任何数据/案例/研究前，四把尺子同时过：

1. **准确性**：数字是否来自原始出处？有没有二手引用导致的漂移？
2. **精确性**：粒度是否匹配论点？"多数"和"63%"是两件事
3. **充分性**：一个例子撑不起一个普遍判断——要么增量、要么把论断收窄到该例子能撑住的范围
4. **代表性**：样本能推广吗？B 端案例推 C 端、北方推全国、单年推长期——都是踩雷区

任一不过关 → 要么换证据、要么收窄论断，不要硬推。

### 律师 vs 侦探姿态（源自《写作是门手艺》第六篇）

写论证的默认姿态是**侦探**，不是律师：

- **律师**（不推荐）：先有结论，只收集支持证据，屏蔽反面。读者能闻出"被说服"的味道，警惕心上来
- **侦探**（推荐）：带着疑问上路，遇到反面线索就写进来，和读者一起把它处理掉。读者感到"我们在一起想清楚一件事"

**操作信号：** 写完一段后问自己——这段里有没有一个让我自己犹豫过的点？有 → 把这个犹豫写出来再处理掉。完全没有犹豫的论证，往往是律师姿态，回去找反面。

### 限定词三维度（源自《写作是门手艺》第六篇）

论断要在"清楚"和"诚实"之间找平衡。过强让读者反感，过弱没有信息。沿三个维度标限定：

| 维度 | 太强 | 刚好 | 太弱 |
|------|------|------|------|
| **覆盖面** | "所有用户都" | "多数中高端用户" | "一些用户可能" |
| **时间跨度** | "长期来看一定" | "未来 2-3 年内" | "也许某一天" |
| **确定度** | "显然""毋庸置疑" | "从目前看大概率" | "或许""说不定" |

**自检：** 加粗的每个判断，问一次"如果读者反过来举一个反例，我能不能站住？"——不能 → 往弱的一侧调半格。

<!-- meta-audit M8：「自承在猜」精度档 -->
> **最高诚实度 = 直接说"这是我的猜测"。** 法则：每篇至少 1 处「内置反对者自辩」或"我承认……但是"形态。把"猜"显式说出来，反而比硬装权威更让读者愿意信。"我想""想来""我至少满足两条"这类措辞都是这一档。

### 理由组织顺序（源自《写作是门手艺》第六篇）

一个核心论断下挂多条理由时，顺序不是随机的：

1. **最强的放首尾**——首位抓注意力，末位留印象，中间段放次强的
2. **按读者质疑烈度升序**——先处理容易接受的，再上硬骨头，读者一路"嗯嗯嗯"到最后
3. **三条为佳**——超过三条记不住，不足三条显得单薄；真有五条就压到三条主线+两条注脚

写完后反向检查：把理由列表倒过来读，如果哪一条放错位置会显得突兀，调整。

### 科学叙事六步（科学/反常识叙事专用）

把学术研究写成读者能一口气读完的故事的范式——像悬念小说一样铺陈一项反常识研究，而不是用"近年来研究表明"开一个教科书腔的头。

**六步骨架：**

1. **找一项最新反常识研究**：直觉认为 A，研究发现却是 B → 反差越大越好
2. **把研究者写成有性格的人物**：不写"某项研究表明"，写"这个 [姓名] 平时怎么样、为什么会做这个研究、做研究时碰到什么"
3. **还原实验场景**：受试者数量、实验室长什么样、给受试者吃什么/看什么/问什么——给读者临场感
4. **从实验抽机制**：为什么会出现 B 而不是 A？机制是什么？——这是"思想"出现的位置
5. **跨域类比**：把这个机制套到另一个场景里（学生考试、夫妻吵架、公司开会）——让读者看到"这事跟我有关"
6. **给读者「这对你意味着」桥梁**：不是"你应该这样做"（那是律师姿态），而是"你下次遇到类似场景可以这样想一下"——把思想权交还给读者

**禁忌：**
- 不要从"近年来研究表明"开头——AI 教科书腔，立刻把读者推远
- 不要在每一步都加权威背书（"哈佛大学""诺贝尔奖得主"），那是律师姿态在卖弄
- 不要在第 6 步给行动清单——这类写法从不教人怎么做，只让你看清一件事

**适用：** 反常识叙事流路由 / 任何"我想给读者一个新的看世界方式"型深度文

## 白描技法（减法子模式 · 可叠加任何路由）

白描是所有路由的**"减法子模式"**，按需调用。当一段话的情绪过于浓烈、形容词堆叠、读起来像 AI 时——切到白描模式重写一遍。

**三条核心：**

1. **名词+动词双拍极简对仗**（禁形容词副词）
   - 纯陈述式：「那个项目融了两轮，最后没上线」——零形容词，事实摆在那
   - 纯物件式：「47 万条记录，10 版废弃的提示词，一份没写完的说明文档」——纯物件，让物件自己说话
   - **量化检验点**（I31，白描比例法则）：抽 300 字算 形/副词 vs 名/动词比例。**1:3 文笔可疑 / 1:4~1:5 接近白描 / 推荐区间**

2. **闲笔荡开**（🔴 限叙事流路由 + 深度文）
   - 主线写到关键处，突然插一句看似无关的环境描写（"窗外有只猫走过""桌上的茶凉了"）——读者紧张感得到泄洪，反而能更接住下文的冲击
   - 与岔题宣告的区别：闲笔不需要"宣告"，是无声转移；岔题需要明示宣告
   - 🔴 **仅限叙事流路由与深度文；资讯 / 成果 / 评测类禁用**（这类要直给干货，关键处插闲笔恰打断读者最想要干货的时刻）

3. **冷收一句**
   - 段落最后一句**只陈述事实，不下判断**。让读者自己得结论
   - 反面教材：「这真是令人深思的一幕。」——AI 标配尾巴
   - 正面：「他没再说话。」——事实陈述，留白给读者

**适用场景：**
- 写沉重话题（避免煽情）
- 描写人物出场（让物件做证据 > 形容词）
- 收尾段（冷收远胜抒情）

**禁忌：** 全文白描容易显冷；建议每篇用 1-2 段白描调性，与其他段落形成密度落差。

## 金句锻造

<!-- meta-audit I26：现象命名小节（在金句锻造表之前） -->
> **现象命名 = 一种特殊金句生成器。** 当你能给一个现象起出一个贴切的新名词（如「功能仓鼠症」「沉没额度依赖」），名字本身就是金句。🔴 **全篇至多 1 个**（不是"至少" -- 配额化的造词是新的公式化，读者一篇里记不住两个新名词），且**必须出现在支撑场景之后**：先让读者看见现象本身（例子/画面/数据），名字最后才落地，像给已经认识的人介绍名字。**禁止**先抛名词口号再用"什么意思？"补丁倒灌解释——那是把认知顺序倒过来压给读者。没有自然长出来的好名字就不造，宁缺毋滥。

> 🔴 **金句节拍器禁令**：① 全篇**加粗的口号式金句上限 2 处**；② 金句必须是**收拢句不是预告句**——场景/论据在前，金句最后落地收住。先抛加粗口号再解释，等于逼读者先背结论再听理由，每节都这么打拍子会把文章变成 PPT。多数段落的最后一句应该只是一个普通的好句子，不是金句。
>
> ⚙ **执行边界（与 writing.md §加粗一致）**：这里的「口号式金句 ≤2」是**磨稿期自觉**，无机器计数门；机器（`verify_bold_density`）只硬拦单块 ≥15 字的整句加粗 + 全篇加粗总量分档上限。两个机制别混为一谈。

| 句式 | 结构 | 示例 |
|------|------|------|
| 对称式 | 前后对称 | "让工具懂人，让人懂账。" |
| 否定-肯定式 | 先否定再重新定义 | "不是模型不够强，是问题问得不够狠。" |
| 因果翻转式 | 因果倒过来 | "不是没时间学，是学了没处用，才更没时间。" |
| 重新定义式 | 意想不到的命名 | "你以为你在用 AI，其实你在替它标数据。" |
| 朴素穿透式 | 最平实最准确 | "省下的那两小时，你根本没拿去休息。" |
<!-- meta-audit M7：金句锻造从 5 → 9 公式 -->
| 逻辑链式 | A≈B≈C 所以 A≈D | "上下文是记忆，记忆是习惯，所以你喂什么上下文，它就养成什么习惯。" |
| 公式化 X=Y-Z | 抽象关系用算式表达 | "焦虑 = 想要的能力 - 肯花的时间""有效产出 = 模型上限 - 提问损耗"（把抽象关系压成一道减法）|
| 双锤连击 | 两个加粗短句叠 punch | "能自动的就别手动。能省的额度就别硬烧。""红线就是红线，热炉就是热炉。" |
| 俗语挪移式 | 把民间俗语扭一下用在新场景 | "拿着锤子，看什么都像钉子。"（用在"刚拿到大模型，看什么都想让它写"）|
<!-- 跨路由技法新增 5 式 -->
| 对照式 (一只手) | "X 一只手 A / Y 一只手 B" 双面冲突 | "一只手裁掉运营, 一只手买爆显卡, 两头烧, 停下来就亏" |
| 揭穿式 (嘴实) | "嘴上 X / 实际 Y" 或 "看似 X / 其实 Y" | "嘴上说绝不用 AI 写稿的人, 收藏夹里躺着八个提示词模板" |
| 阶梯递进式 | 三层条件 → 行为, 末层升华成情感/记忆/价值 | "只有五分钟, 你让它写句文案; 有一个钟头, 你让它搭个流程; 等你敢把一整天交给它, 它才真的开始替你干活" |
| 戳穿式比喻 | "X 这就像 [生动场景] / [反差行为]" | "这就像雇了个天才助理, 却只让他每天帮你复制粘贴" |
| 层级反差式 | "[数据 X] + 反差对照 (本应 A 却是 B) + 反讽戏谑" | "一次调用几分钱, 一个月账单四位数 — 省下的人力钱, 全喂给了云厂商" |

> 🔴 **金句卡片的排版样式**：上面讲的是「怎么写」金句；当需要把一句金句**单独提出来做成卡片**强调时，视觉一律用 [templates/quote-card.html](../templates/quote-card.html) 的「**左竖条 + 极浅色文本框**」样式（深色引文 + 主题色出处右对齐），轻盈融入正文。**禁止**旧版「整块主题色渐变盒 + 白字 + 大号装饰引号」 -- 满底色太厚重割裂，且装饰用的 `&ldquo;`/`&rdquo;` HTML 实体在微信里会渲染成乱码（"idqu"/方框）。卡片里要引号就写中文「」/""，不加任何装饰性 HTML 实体。单篇加粗口号式金句仍 ≤2。

## 结尾技法

- **结尾不总结。** 结尾是最后一个发现，或者一扇门——指向你没写但读者会自己去想的方向
- **意象化留白（最推荐）：** 3-4 个具象短句，不出现抽象名词
- **对话式寄语：** "你可以试试""从这一刻开始也不晚"
- **回扣开头闭环：** 呼应开篇场景或问题
- **禁用八股**：详见 `anti-ai-filter.md` § 2.1。craft-techniques 只谈"如何写"，禁忌清单单点收口。
- **禁止：** "下一篇聊聊XXX"式的预告收尾（像营销号）
- 🔴 **默认冷收**（一句只陈述动作或事实的短句收住，不解释不升华，见 playbook `cold_close`），收尾形态从 [anti-ai-filter.md §1.5 收尾多样性](anti-ai-filter.md) 九种里按内容自然选。**原"三段式收尾（回到故事 → 金句引用块 → 互动开放问题）"已废除** -- 它让改造前后每篇文章无一例外问句收尾，是制度性的模式固化。互动提问的职能移到**排版层**（导读栏 / 文末留言引导位），不占正文结尾。
