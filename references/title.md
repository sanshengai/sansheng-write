# 标题锻造（内联）

> 「写 标题」阶段由当前写作模型直接锻造，不调用外部标题 skill。本文件是公众号外标题和 X 标题的**唯一来源**：x-article.md、执行卡、大纲模板只引用这里，不另写公式。
> 2026-10-21 重写：旧版「唯一公式 + 四种填法（原话型默认首选）」连续产出作者不满意的标题，病根见 §为什么旧规则出不了好标题。旧版那套已整体废除，不要从旧稿、旧判例或别的 skill 里捡回来。

## 🔴 核心写法：对象 + 可得物

标题只做两件事：让对的人一眼认出**写的是什么**，看出**读完能拿走什么**。不负责制造好奇，不负责表达态度。

```
[具体对象] + [读者能拿走的东西]（数字取自正文）
```

- **对象**：读者会去搜的专名 -- 工具、模型、产品、书、人、事件。属性不自明就补属性词（`爱因斯坦传`、`德鲁克 5 本书`、`中美 9 款 Agent`）。抽象词（底层逻辑 / 范式 / 赋能 / 新红利）不是对象。
- **可得物**：读完真能拿走的具体东西 -- 做法、规则、清单、方案、提示词、选型结论、一个可复现的结果。它必须是正文里**有专节或有落点**的东西，标题里的数字也必须在正文里找得到。
- 两段之间用冒号、逗号或直接连写都行，**怎么顺口怎么写**，不强求冒号。

作者明确喜欢的两条改写，就是这个写法的样子：

| 原标题 ❌ | 改写 ✅ | 为什么 |
|---|---|---|
| 德鲁克五本书，反复讲的不是"怎么管人" | **德鲁克 5 本书，整理成 3 条今天能用的管理规则** | 原题是一句判断加翻转；改写给对象（5 本书）和可得物（3 条规则，来自正文「今天最值得拿走的三条管理规则」） |
| Claude 被封后的 72 小时 | **Claude 被封后，我的替补方案：Claude Code + Kimi Code + Antigravity** | 原题只有时间框，读者不知道里面有什么；改写直接列出方案本身（正文「老将留守 / 新兵上场 / 备用梯队」） |

## 🔴 四种写法（按默认优先级出候选）

| # | 写法 | 模板 | 什么时候用 | 例 |
|---|---|---|---|---|
| A | **对象 + 可得物** 🟢 默认 | `[对象]，[整理成 / 给出] [N 条 / 一份 / 一套] [可得物]` | 绝大多数篇：蒸馏、教程、工具、方法、清单 | `德鲁克 5 本书，整理成 3 条今天能用的管理规则` |
| B | **我做了什么（+ 结果 / 方案）** | `我用 [工具] 做了 [东西]：[结果]` / `[处境]，我的 [方案]：[方案内容]` | 作者亲手做成、亲身踩过的事 | `Claude 被封后，我的替补方案：Claude Code + Kimi Code + Antigravity`<br>`Claude Code 清理家里的电视：开机广告没了，内存多出 437 MB` |
| C | **选型 / 对比（带依据）** | `[A] 和 [B] 怎么选：[依据或结论]` / `N 款 [X] 横评：[谁适合谁]` | 多个对象横向比较 | `中美 9 款 Agent 横评：按三种人给选法` |
| D | **事件 + 解读** | `[谁] [发布 / 做了] [什么]：[一句关键事实]` | 资讯、发布、行业数据 | `幼师学校改做养老、江西教师招聘少了八成半：四组数字看人口变化` |

- **A 是默认**。拿不准时先写 A；B / C / D 是 A 的变体，差别只在可得物是「我的结果」「选法」还是「关键事实」。
- **原话 / 观点句不再是填法**：主角原话（`曾国藩传：结硬寨，打呆仗`）、作者判断（`AI 时代小公司真正的机会……`）默认不出候选。只有作者**明确要求**用原话或观点做标题时才写，并且仍要过下方禁用清单；这时把原话放冒号后、对象放前面。原话和判断的正常位置是正文第一行、封面 L2 或导读。
- **数字**：只用读者一眼懂价值的规模量（5 本书 / 9 款 / 437 MB / 3 天 / 82 个版本），必须在正文出现过且核实过。写精确值带指涉（「29 个预装应用停掉，空闲内存 551 MB 涨到 988 MB」，不写「几十个应用、内存多了不少」），不为了有数字硬塞。这条同样管 X 主帖说明文字（见 [x-caption.md](x-caption.md)）。内部编号（N 章 / 第 N 期 / v2）不是规模量。
- **自夸定位词**（全网最全 / 最好 / 第一 / 唯一）默认不用；作者要为某篇关键推广篇花一次时，正文必须有自证段，同一栏目不连用，标题 + 封面 + 导读合起来只算一次。

## 🔴 禁用清单（噪头）

出现任何一项就改，不靠「这次情有可原」放行：

| 类 | 词 / 句式 | 改法 |
|---|---|---|
| 否定、催促开头 | 别再… / 还在…？ / 千万不要 / 你一定要 / 建议收藏 / 赶紧 | 删掉，直接写对象 |
| 营销夸张 | 竟然 / 居然 / 我去 / 震惊 / 太绝了 / 封神 / 白嫖 / 保姆级 / 一文讲透 / 彻底讲透 / 天花板 / 最强 / 神器 / 魔法 / 终于 / 根本 / 细思极恐 / 万万没想到 | 换成具体结果或数字 |
| 空修饰前缀 | 深度 / 重磅 / 硬核 / 干货 | 删 |
| 悬念、揭穿 | 真相 / 这背后 / 没想到 / 才发现 / 原来真正的 / 你以为 / 你买过的…不是 / 多半不是 / 其实是 / 看似…其实… / 表面是…背后是… / …才是关键 / 真正决定 X 的是它 | 直接写结论 |
| 翻转句 | 不是 A，而是 B / 不是 A，是 B / 与其说 X，不如说 Y | 只写 B，并补上可得物 |
| 问句当标题 | 「为什么你的…？」「…吗？」「到底是什么？」 | 改成陈述句；选型可写「怎么选」，但冒号后必须给依据 |
| 只有观点 | 一句判断或口号，看不出能拿走什么（「懂 AI 并不能让你赚到钱」「生意变了」） | 判断挪到正文第一行，标题改 A / D |
| 标点 | 感叹号、省略号（`…` / `...`）、全角破折号 `——` | 删；需要破折号时用 `--` |
| X 版前缀 | X 标题里的 `洞察 \|`、`分享 \|` 等分类前缀，期数、内部编号 | 去掉（`x_article.py` 会自动剥前缀，仍要求源稿就不写） |

`pipeline.py preflight` 的标题门会把能用正则判定的那部分标出来（见 §机器检查）；语义部分（有没有可得物、是不是只有观点）只能靠下方自检。

## 长度：习惯，不是上限

- 不设字数上限，也不为了字数砍词。**唯一判据是念一遍就懂**：每个词都在交代对象或可得物，长一点没关系（`Claude 被封后，我的替补方案：Claude Code + Kimi Code + Antigravity` 就该这么长）。
- 习惯上中文正文标题 20--30 字最常见；超过 40 字时先检查是不是在堆名词，而不是去数字数。
- **不许为了变短换成更抽象的话**。旧版「≤20 / ≤30 字，超了就砍」会把「3 条管理规则」这类可得物挤掉，只剩一句更抽象的判断。
- 平台硬限只有一处：公众号草稿接口 `draft/add` 的 `title` 文档写「不超过 32 个字」，超了可能被拒（45883 `title size out of limit`；编辑器实测口径更宽，约 64 字）。所以外标题含前缀超过 32 字位时，preflight 只提示一句「上传前确认」，不拦。X Article 标题没有需要我们管的上限。小红书笔记标题平台限 20 字（中文 1、英数 0.5），那是图文页标题，按 [xhs-storyboard.md](xhs-storyboard.md) 另写，不倒逼公众号外标题。
- 公众号列表 / 分享卡前 16 字左右最稳定可见，**对象尽量放在前 16 字里**。

## 公众号和 X 的区别

同一篇稿子，标题主体用同一个 A / B / C / D 写法，只在外壳上不同：

| | 公众号外标题（`article-meta.yaml:title`） | X 标题（`定稿.x.md` frontmatter `title`） |
|---|---|---|
| 前缀 | 带 `标签 \| `（见 §第一步） | 不带 |
| 主体 | A / B / C / D | 同一句；公众号版若作者要求用了原话，X 版必须改回 A |
| 人物 / 书籍篇 | `曾国藩传，……` 这类也走 A：对象 + 能拿走的 N 条 | 同左 |

## 🔴 出候选：5 个，先找对象和可得物，再成句

1. **定标签**（只给公众号版用，见 §第一步）。
2. **找对象**：这篇读者会搜的专名是什么？写 1--2 个，属性不自明补属性词。
3. **列可得物**：读者读完能拿走什么？把正文里的做法、规则、清单、方案、选型结论、具体结果逐条列出来，每条写明**在正文哪一节**。一条都列不出 → 这篇只能用 D，或者先回去补正文。
4. **成句**：A 写 2 个，B / C / D 里合适的写 2 个，剩 1 个自由（仍限 A--D）。全部陈述句。
5. **补数字**：只放正文已核实、读者一眼懂的规模量。
6. **过 7 条自检**，不过就当场改，改不好就废掉。

每个候选交出四行，缺一行不算候选：

```
候选：<标签 | 标题主体>
写法：A / B / C / D
对象 / 可得物：<专名> / <能拿走的东西>
兑现：<正文哪一节承载这个可得物；标题里的数字出自哪一句>
```

## 🔴 7 条自检（每个候选逐条过）

1. **兑现**：标题里的可得物和数字，正文哪一节兑现？要求是专节或落点，不是路过的一句。
2. **谁 + 什么**：念给不了解背景的人听，他能说出「写的是什么」和「能拿走什么」吗？只说得出前一半 → 补可得物。
3. **「读完你可以……」**：在标题前加这几个字，读起来具体、而且是真的吗？接不上（如「读完你可以……反复讲的不是怎么管人」）→ 重写。
4. **噪头扫描**：逐项对一遍禁用清单；问句、感叹号、省略号、翻转句、揭穿句一个都不留。
5. **可替换**：换个作者、换篇文章，这个标题还能原样用吗？能 → 换成本篇独有的对象或数字。
6. **顺口**：念一遍就懂吗？要读两遍就删修饰语、拆名词堆；不许换成更玄的说法，也不许只为变短删掉可得物。
7. **平台**：公众号版有 `标签 | ` 前缀；X 版没有前缀、没有期数；数字、版本号、价格已核实；破折号用 `--`。

## 排序 + 推荐

先按自检筛掉不过的，再按「可得物越具体越靠前」排：有数字和具体清单的 > 只有类别的（「几步」「方法」）。默认推荐 A；作者亲手做的事推荐 B。推荐时一句话说明理由。

## 🔴 为什么旧规则出不了好标题（2026-10-21 复盘，别再捡回来）

对照作者 35 篇已上线 X 稿的标题（来自公众号外标题去掉前缀），作者不满意的标题几乎都是旧规则**按字面执行**的结果：

| 旧规则 | 它产出的标题 | 毛病 |
|---|---|---|
| 「冒号后一句由正文主干兑现的话」，兑现判据是「落点 / 结论段有分量」 | `德鲁克五本书，反复讲的不是"怎么管人"`、`格拉德威尔五本书，反复拆穿了同一种错觉`、`心理学六本书：直觉靠不靠谱，是个假问题`、`拿破仑：他把胜利变成一套系统，也被这套系统拖垮` | 正文最有分量的一句往往是**判断**，于是标题全成了观点句；读者看不出能拿走什么 |
| 原话型「默认首选」，有原话时 2 个名额排最前 | `曾国藩传：结硬寨，打呆仗`、`特斯拉 Cybercab：马斯克说它是「轮子上的休息室」` | 原话是口号形态，在 X 上属于表现最差的「观点 / 口号」一档 |
| 「能带走的 > 产品参数」，把「785 封原文」「四本传记蒸馏成一页」判为「参数无感」 | 同上 | 等于明文把数字和可得物从标题里赶走，再用「一句话或一个处境」顶上 |
| 处境型（「他当时怎么办」式的坎） | `Claude 被封后的 72 小时`、`广义相对论那八年，他怎么走过来的` | 只有时间框，没有内容 |
| 权重「那句话能不能让对的人停下来 50%」 | `最强的 AI 干活神器 -- 中美 9 款 Agent 怎么选`、`「四头」灰犀牛已在面前，不要视而不见`、`几十块钱的 AI 课，卖的其实是「目标」` | 「停下来」被理解成刺激，于是出现最强、口号、揭穿 |
| 「不是 A 而是 B」在机器门里只提示、「其实是」不在正则里 | `AI时代，小公司真正的机会，不是做大，而是把一个小市场做深`、`德鲁克……不是"怎么管人"` | 翻转句一路放行 |
| 硬长度「≤20 / ≤30 字，超了就砍」，且「长度计入前缀」 | 正文标题只剩约 26 字，装不下对象 + 可得物 + 数字 | 只好压成更抽象的一句；`3 条管理规则` 被压没了 |
| 机器门硬要求「锚点：一句话」冒号结构 | 逼每个标题长成「专名：一句话」 | 作者喜欢的 `德鲁克 5 本书，整理成 3 条……` 没有冒号，旧门会判不过 |

同一批稿里写得好的，恰好都是新写法：`Claude Code 清理家里的电视：开机广告没了，内存多出 437 MB`、`Alex Hormozi 的方法论，我整理成了一页`。对标数据也一致：中文 AI 长文里「对象 + 可得物」收藏中位数最高，噪头、观点句、问句排倒数（`/workspace/title-research/report.md` 的样本，2026-10-21 快照）。

## 🔴 第一步：定分类标签前缀（公众号外标题，出候选前先做）

公众号外标题**一律带 2 字分类标签前缀**，格式 `标签 | 标题主体`（半角竖杠 ` | `，两侧各留一空格）。它是读者在信息流里一眼归类的信号，也与网站 / RSS 的对外分类同源。**X 标题不带前缀。**

> 🔴 **必须在出候选这一步就锻进每个候选，不是发布时才补**。根因教训：标签过去只写在发布 / 归档阶段的 `outward_category` 字段，导致盲选交给作者的全是裸标题，选定后标签就丢了。

**定标签：7 选 1，走裁决链**（自上而下首个命中即定，与 `templates/article-meta.template.yaml` 的 `outward_category` 同源）：

| 标签 | outward_category | 命中条件 |
|---|---|---|
| 教程 | tutorial | **面向新手的系统性教学**（手把手、从零、系统课）——工具安利 / 成果展示不算，归「分享」 |
| 精选 | picks | 多个（≥3）横向合集 / 清单 / 榜单 |
| 分享 | share | 自创成果（工具 / skill / 网站新功能）、亲测好物安利、珍藏书籍推荐——「我做了 / 我在用 / 我觉得好」 |
| 行业 | industry | 主体是某垂直行业本身（地产 / 工程…） |
| 资讯 | news | 刚发布 / 新品 / 大事件（新闻播报视角，无亲测背书） |
| 洞察 | insight | 对 AI / 行业的趋势判断 · 观点 |
| 随笔 | essay | 个人成长 / 生活（兜底） |

裁决链顺序：**教程 > 精选 > 分享 > 行业 > 资讯 > 洞察 > 随笔**。「分享」与「资讯」的分界 = 有没有作者亲测 / 自创背书。定完标签后：

1. 5 个候选**都带同一个 `标签 | ` 前缀**，变化的只是竖杠后的标题主体；
2. 把定的 `outward_category` **立即回填 `article-meta.yaml`** -- 发布 / 归档（`pipeline.py archive/finalize`）直接复用，archive 不再二次判类。

标签是分类，不是标题的一部分修辞：「洞察」篇的标题主体照样要有可得物，不能因为是观点篇就写成观点句。

## 机器检查（`pipeline.py preflight` → `contracts.audit_title_contract`）

| 档 | 查什么 |
|---|---|
| 阻断（fail） | 缺 `标签 \| ` 前缀；内部编号（N 章 / 第 N 期 / v 号）；揭穿式反差（你买过 / 你以为 / 多半不是 / 表面是…背后… 等）；悬念词；标题党词 |
| 提示（warn，不拦） | 禁用清单里的噪头词、问句、感叹号 / 省略号、翻转句、「其实是」、自夸词；整句没有任何分段（看不出对象和可得物）；含前缀超过 32 字位（公众号接口限制，上传前确认） |
| 不查 | 字数上限（已取消）；有没有可得物、是不是只有观点（语义判断，靠 7 条自检） |

`x_article.py` 的发前体检对 X 标题跑同一份噪头提示，另外提示残留的分类前缀；都只提示，不阻断 `--publish`。

## 品牌硬约束

- 🔴 破折号一律用两个英文连字符 `--`，禁止全角 `——`
- 模型版本号 / 价格 / 日期等具体数字必须已核实，不确定先查再写
- 期数只属于固定栏目 / 日更系列，从 v1 起算；单篇文章不许拿章节数、内部版本号充规模
- 🔴 **封面 ≠ 外标题，但对象（关键词锚点）必须两处都出现**：分工见下方 §封面与外标题怎么分工。**blueprint 蓝图闸启用时**，每个外标题候选须当场配好封面文案（L1/L2 与 2--4 个可视化事实），组成「标题+封面」配套方案一包交付作者选定（见 [outline.md 步骤 8](outline.md)）。

## 🔴 定稿标题后：同时锻造「封面文字包」（六项必填 + 一项可选）

外标题定下来后**不要停** -- 封面上的字是另一套文案，必须在这一步一并定死，
不能留到生图时让模型现挑。产物写进 `article-meta.yaml:lead`：

| 字段 | 是什么 | 硬约束 |
|---|---|---|
| `lead.line1` | 封面 **L1 主标题** | **4--7 个汉字位**（数字/半角按 0.5 折算），硬上限 8 |
| `lead.line2` | 封面 **L2 副标题** | **≤ 12 个汉字位**，单行 |
| `lead.accent` | L2 里染主题色的**落点词** | **2--5 个字**，且必须是 line2 的**结尾**子串 |
| `lead.tag1` | 底部标签胶囊 1 | **≤ 4 个汉字位**，必填 |
| `lead.tag2` | 底部标签胶囊 2 | **≤ 4 个汉字位**，必填，且不得与 tag1 相同 |
| `lead.tag3` | 底部标签胶囊 3 | **≤ 4 个汉字位**，可选；只进封面，导读栏仍排两项 |
| `lead.ghost` | 标题后方的**半隐英文** | **2--3 个全大写 ASCII 词组，用 `×` 连接**；每组 ≤ 14 字符、整行 ≤ 32 字符，必填 |

`lead.ghost` 举例：`QUOTA × BURN RATE × DASHBOARD`、`ACCOUNT × PLAN B × WORKFLOW`、
`CHANGELOG × 82 RELEASES × TWO ROADS`。取本篇三个关键概念的英文，读者扫一眼能和中文标题对上；
不写品牌名、账号名、期号。它只有 8%--14% 不透明度，是背景纹理，规格见 `cover-styles.md`。

`lead.subtitle` 是文章导读副标题，只允许字符串，**不进入封面**。封面编译器只认上表七项；
缺必填项、字段错位或超长都直接停止，不允许生图模型代填。

**上限为什么是硬的**：L1 要占画布高 12%--14% 才能成为视觉主体，反推左区
只放得下约 8 个汉字。**超一个字，模型就只能缩字号**，封面规范再严也压不住 --
封面翻车正是这么来的（详见 `cover-styles.md` 的字号层级节）。

**下限没有硬约束，别为了凑字数注水**：作者原话 --
「四个字也挺好……如果有一些文章，四个字五个字能说清楚的，我觉得也够了，没关系。」
「生意变了」正是四字范例。**能四个字说清就四个字**，
6--7 字是舒适上沿，8 字是不可越的硬顶。

**两个封面标签的例子**：

```yaml
lead:
  line1: "额度重置"
  line2: "排进一张日历"
  accent: "一张日历"
  tag1: "额度"
  tag2: "预警"
  ghost: "QUOTA × RESET × CALENDAR"
```

**落点词怎么挑**：选那句话的**语义落点**，也就是读者读完最该记住的动作或结论。
好例：「从抢年轻人，到**抢老人**」/「两端装上，一直**看得见**」/「排进**一张日历**」。
坏例：染开头、染虚词、染满整行。**L1 一个字都不染**。

## 🔴 封面与外标题怎么分工（对象有意重复，可得物必须互补）

很多读者**只看图**。图上没有「爱因斯坦传」四五个字，他就不知道这是谁的传记、
更不会往下看文字标题。所以：

| | 对象（关键词锚点） | 可得物 |
|---|---|---|
| **外标题**（列表页 / 朋友圈 / 分享卡） | 必须有 | 可得物（A--D 写法之一），不设字数上限 |
| **封面 L1 / L2**（缩略图，先被看见） | **必须有，就放 L1** | 换一个角度（另一个数字 / 物件 / 结果），≤12 字位 |

两条铁律：

1. 🔴 **锚点必须两处都出现，这是有意重复，不是冗余。** `lead.line1` 就写关键词锚点本体
 （`爱因斯坦传` / `曾国藩传` -- 恰好落在 4--7 字位的舒适区）。
 人物 / 品牌 / 作品为主题时这条已由 `visual_contracts.py` 机器强制（`cover_identity` 必须
 显式进 L1/L2，底部小标签不算）。**旧版曾写「封面不复述外标题核心关键词」，已删除** --
 那条会让封面丢掉唯一能让读者认出主角的信息。
2. 🔴 **可得物不许重复：L2 与外标题对象后面那部分必须换一个角度，且不共用主要实词。**
 外标题写了「3 条管理规则」，封面 L2 就给另一个正文事实（年份跨度、一张地图、一个结果数字）。
 **整句照抄外标题进封面，或把同一句话砍短放上去，都判不通过。**

**两项验收**（作者原话：既能剥离开来独立看，又能结合起来看，且不重复）：

- **独立成立**：只看封面 → 说得出「这是谁的什么 + 为什么值得看」；只看外标题 → 说得出
 「这是什么 + 能拿走什么」。任一说不出 → 那一侧信息不足。
- **并排不重复**：把 L2 和外标题对象后面那部分并排读一遍 -- 在说同一件事就改 L2，别改锚点。

**自夸配额跨字段计**：「全网最全 / 最好」在**标题 + 封面 L1/L2 + 导读**里合起来只算一次额度；
不许标题避开自夸、封面又自夸一遍，那等于偷偷花掉了同一笔信用。

### 两个配套范例

```yaml
# 德鲁克篇：外标题给「3 条规则」→ 封面给年份跨度和地图（正文：1946--1999 年五本代表作的思想演变地图）
title: "分享 | 德鲁克 5 本书，整理成 3 条今天能用的管理规则"
lead:
  line1: "德鲁克 5 本书"        # 对象本体，5.5 字位；与外标题有意重复
  line2: "1946 到 1999 一张地图" # 9 字位；换角度，不与「3 条规则」共用实词
  accent: "一张地图"            # line2 结尾 4 字
  tag1: "管理"
  tag2: "思想地图"
  ghost: "DRUCKER × 53 YEARS × MAP"
```

```yaml
# Claude 被封篇：外标题列方案 → 封面给「怎么编队」
title: "分享 | Claude 被封后，我的替补方案：Claude Code + Kimi Code + Antigravity"
lead:
  line1: "Claude 被封"          # 5 字位
  line2: "ORCA 编成一支队"       # 7 字位
  accent: "一支队"
  tag1: "封号"
  tag2: "替补"
  ghost: "BANNED × PLAN B × ORCA"
```

两篇的读法都是：**图上先认出是什么、再看到另一个硬事实；文字标题给能拿走的东西。** 拆开各自成立，合起来不重复。

**和外标题的其他区别**：外标题可以长、带「分享 |」前缀；封面必须短、必须一眼读完，
**不要把外标题原样塞进封面**。

输出时把五项一起给出，例如：

```
封面文字包（已回填 article-meta.yaml:lead，含 ghost）
  L1  54 次额度重置        （7 字位 ✓）
  L2  排进一张日历          （6 字位 ✓）
  染  一张日历              （4 字，line2 结尾 ✓）
  标签 额度 / 预警           （各 ≤ 4 字位，且不重复 ✓）
```
## 输出格式

直接在对话中输出，不写文件、不生成时间戳：

```
分类标签：分享（outward_category: share） -- 已回填 article-meta.yaml

[推荐] 1. 分享 | 德鲁克 5 本书，整理成 3 条今天能用的管理规则
       写法 A ｜ 对象 德鲁克 5 本书 ｜ 可得物 3 条管理规则
       兑现 「今天最值得拿走的三条管理规则」整节
       理由 对象和可得物都在，数字来自正文小标题

2. 分享 | 德鲁克 1946--1999 年 5 本代表作：一张思想演变地图
   写法 A ｜ 对象 德鲁克 5 本代表作 ｜ 可得物 思想演变地图
   兑现 导读与地图页入口
...
X 版：德鲁克 5 本书，整理成 3 条今天能用的管理规则
```

首行先亮标签 + 已回填 meta；5 个候选统一带 `标签 | ` 前缀，**每个都带写法、对象 / 可得物、兑现三项**；最后一行给 X 版（去前缀，作者用了原话时改回 A）。用户要更多就继续迭代。
