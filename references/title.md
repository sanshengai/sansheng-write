# 标题锻造（内联）

> 「写 标题」阶段由当前写作模型直接锻造，不调用外部标题 skill。理由：套路化的「戏剧化悬念」标题与本 skill「直球说清、不靠噱头」的调性不合。本文件 = 起标题方法 + 品牌校准，标题逻辑收在本 skill 内部；**唯一公式见下节，与它冲突的一切表述（含其他 reference）以它为准**。

## 🔴 唯一公式（凌驾本文件与其他 reference 里一切「钩子 / 悬念 / 反差」表述）

```
分类标签 | 可搜索关键词 + 一句把全文主旨浓缩到底的话
```

两个零件，缺一不可：

1. **可搜索关键词**（紧跟竖杠、放最前面）：读者真会去搜、平台真会拿来分发的**专名** -- 人物（爱因斯坦 / 曾国藩）、公司与产品（Anthropic / Claude Code / 某模型）、书名、事件名。**1--2 个就够**，多了挤掉主旨。抽象组合词（涌现 / 范式 / 赋能 / 底层逻辑）不是关键词，不许拿来顶替。
2. **一句把主旨浓缩到底的话**：把「**这篇整体交付了什么**」压成一句。验收判据是**覆盖性** -- 只读这一句，读者就该知道整篇讲什么、自己能拿到什么。

**平铺直叙就是最优解。** 标题不负责制造好奇，负责让对的人一眼认出「这篇是写给我的」。花招（悬念 / 反差 / 卖关子 / 故作玄虚）一律不用 -- 不是"少用、慎用"，是不用。

## 🔴 六条硬禁（判例见下节）

1. **禁揭穿式反差**：「你买过的 X，其实不是他写的」「你转发的那些 Y，多半不是他说的」-- 先假设读者错了、再纠正他，这类句式一律不用。
2. **禁悬念 / 卖关子 / 故作玄虚**：不留白、不设谜，不用「真相是」「这背后」「没想到」「才明白」。
3. **禁内部结构编号**：「15 章」「16 章」「第 3 期」「v2」这种只有作者知道含义的切分数不进标题 -- 读者不知道一章是多少，也不关心 15 和 16 差在哪。**数字要选读者一眼懂价值的规模量**（4 本书 / 52 万字 / 785 封原文 / 3 款横评），不选内部编号。
4. **禁把局部发现当主旨**：见下节。
5. **禁抽象空壳**：赋能 / 新生态 / 底层逻辑 / 范式转移 -- 删掉后句意不变的词一律删。
6. **禁标题党词**：震惊 / 竟然 / 细思极恐 / 万万没想到 / 太绝了。

## 🔴 主旨 ≠ 正文里最刺激的那个发现（过去翻车的根因）

本节位置上原先有两条互相拆台的指令：一条要「直球 + 关键词前置」，另一条要
「先问自己『这篇最反常识的一句话是什么』，把它做成标题」，还补了一句「标题只引介、
不概括全文」。两条都满足不了时，模型选了更具体、更可执行的那条 -- 于是每次都去正文里
挑一个最有反差的细节做成揭穿句，主旨反而进不了标题。**后两条已删，别再从别处捡回来。**

现在的口径：**竖杠后那句话概括的是「这篇 / 这个产物整体是什么、覆盖了什么、读者能得到什么」**，
不是其中最有戏的一条。局部发现留给导读、封面 L2 和正文首屏，它们各有位置。

### 判例（真实翻车，作者逐条否掉）

| 实际发布 ❌ | 病灶 | 改法 ✅ |
|---|---|---|
| `洞察 \| 「爱因斯坦」16 章：你转发过的那些名言，多半不是他说的` | ①「16 章」是内部编号，读者无感；② 后半句是正文里一条局部发现的揭穿式反差，读完仍不知道这篇整体给什么 | `洞察 \| 爱因斯坦：四本传记蒸馏成一页，每句都能点回原书` |
| `洞察 \| 「曾国藩」15 章：你买过的《冰鉴》，不是他写的` | 同上；且反差本身不成立 -- 绝大多数读者没读过《冰鉴》，"你买过"这个前提是假的，反差感为零 | `洞察 \| 曾国藩：家书奏稿日记蒸馏成一页，785 封原文逐条可查` |

> **反差句有个隐性前提**：它要求读者心里**先有那个错误认知**。读者没有，反差就落空，
> 只剩一句莫名其妙的否定。动笔前问一句：这个"你以为"，一百个读者里有几个真的以为？
> 答不上来就别用反差，改回正面陈述。

## 三步锻造法（照做，比凭感觉稳）

1. **先写"这篇到底给了什么"**：不管好不好听，用一句大白话把全文交付写出来（可以先写到 40 字）。这一步只要**准**，不要美。
2. **补关键词**：从那句里挑出（或补上）1--2 个真能被搜的专名，挪到最前面。
3. **压长度**：把第 1 步那句压进下方长度额度。压的时候删修饰、删虚词，保住主语和动作；**不许为了压字数换成一句更玄的话**。

## 角色

当前写作模型拿到内容后直接给标题。不是套模板凑名字 -- 是让读者在信息流里一眼认出「这跟我有关、有用」。标题是高速路旁的广告牌：一扫而过，**说清楚「是什么、有什么用」的，比卖关子的更留得住人**。

## 🟢 品牌校准（与通用起标题最不同的地方）

本 skill 调性 = 真实、务实，靠说清楚吸引，不靠噱头。所以：

- **覆盖 > 戏剧**：标题的吸引力来自「一眼看清这篇值不值得读」，不是套路化悬疑句式。也不要硬套「为什么…」「这背后…」「真相是…」的空壳。
- **具体 > 聪明**：宁可朴素说清一件具体的事，也不要为了显文采而绕。一个具体的人 / 数字 / 动作 / 画面 > 一个漂亮的抽象概括。
- **不标题党**：标题承诺的，正文必须兑现；反过来，正文的主干必须在标题里有交代，不许只挑一个边角撑门面。
- **关键词前置**：文章核心是「读者一眼就该认出的事」（某新模型发布 / 某平台改版 / 某人物 / 某事件）时，把那个专名放竖杠后最前面，后半句紧接着给主旨浓缩。

## 权重

**覆盖性 60% × 关键词命中 30% × 顺口 10%；戏剧性不计分。** 恰当是地基 -- **宁可平，不可玄。**

## 🔴 第一步：定分类标签前缀（出候选前先做，5 个候选统统带前缀）

本 skill 的对外文章外标题**一律带 2 字分类标签前缀**，格式 `标签 | 正文标题`（半角竖杠 ` | `，两侧各留一空格；如「精选 | 三款工具横向对比」）。它是读者在信息流里一眼归类的可见信号，也与网站 / RSS 的对外分类同源。

> 🔴 **必须在「出候选」这一步就锻进每个候选，不是发布时才补**。根因教训：标签过去只写在发布 / 归档阶段的 `outward_category` 字段（一句注释、无执行点、且晚于标题盲选），导致盲选交给作者的全是**裸标题**，选定后标签就丢了 -- 近期只有个别文章偶然补上。把「定标签」提到出标题第一步，前缀随候选一起盲选，才不会漏。

**定标签：7 选 1，走裁决链**（自上而下首个命中即定，与 `templates/article-meta.template.yaml` 的 `outward_category` 同源，保唯一归类）：

| 标签 | outward_category | 命中条件 |
|---|---|---|
| 教程 | tutorial | **面向新手的系统性教学**（手把手、从零、系统课）——工具安利 / 成果展示不算，归「分享」 |
| 精选 | picks | 多个（≥3）横向合集 / 清单 / 榜单 |
| 分享 | share | 自创成果（工具 / skill / 网站新功能）、亲测好物安利、珍藏书籍推荐——「我做了 / 我在用 / 我觉得好」 |
| 行业 | industry | 主体是某垂直行业本身（地产 / 工程…） |
| 资讯 | news | 刚发布 / 新品 / 大事件（新闻播报视角，无亲测背书） |
| 洞察 | insight | 对 AI / 行业的趋势判断 · 观点 |
| 随笔 | essay | 个人成长 / 生活（兜底） |

裁决链顺序：**教程 > 精选 > 分享 > 行业 > 资讯 > 洞察 > 随笔**。「分享」与「资讯」的分界 = 有没有作者亲测 / 自创背书（分享是"我用过 / 我做的"，资讯是"它发布了"）。定完标签后：

1. 下面 5 个候选**每个都带同一个 `标签 | ` 前缀**（同篇标签唯一，5 个候选前缀相同，变化的只是竖杠后的正文标题）；
2. 把定的 `outward_category` **立即回填 `article-meta.yaml` 的 `outward_category` 字段** -- 发布 / 归档（`pipeline.py archive/finalize`）直接复用它，保证标题里的标签与网站 / RSS 完全一致，archive 不再二次判类。

## 执行：出 5 个候选，覆盖 5 种策略

**5 个候选全部是直球版**，差别只在「主旨从哪个面切」。旧版的「问句 / 冲突悬疑」策略档已删除，不要自行补回。

| # | 策略 | 说明 |
|---|------|------|
| 1 | 主旨直陈 | 关键词 + 全文主旨一句（🟢 默认首选） |
| 2 | 规模 / 覆盖 | 关键词 + 读者能感知的规模量（几本书 / 多少万字 / 几款横评 / 覆盖到哪） |
| 3 | 读者收益 | 关键词 + 读完能做成什么、能省掉什么 |
| 4 | 具象落点 | 关键词 + 一个具体数字 / 动作 / 画面替抽象概念 |
| 5 | 自由 | 前四种的组合；仍须逐条过六条硬禁 |

每个标题附一句话：只看这个标题，读者能知道整篇讲什么。**每个候选前统一带第一步定好的 `标签 | ` 前缀**（前缀不占策略差异，变化只在竖杠后的正文标题）。

## 排序 + 推荐

按上方权重（覆盖性 60% / 关键词 30% / 顺口 10%）排序，标注推荐第一名 -- **覆盖性最高、关键词最实的排前面**。

## 品牌硬约束（出标题前逐条过）

- 🔴 破折号一律用两个英文连字符 `--`，禁止全角 `——`
- 长度：对外标题（封面 / 简介 / 小红书）≤ 20 字为佳，微信正文标题 ≤ 30 字为上限，超了就砍。**长度计入分类标签前缀**（`标签 | ` 约占 4 字），超限先砍竖杠后的正文标题、不砍标签。小红书算法计字：中文 / emoji 计 1 字、英数计 0.5 字、空格不计
- 模型版本号 / 价格 / 日期等具体数字必须已核实，不确定先查再写
- 标题含对外期数 / 版本号时从 v1 起算（不照搬内部 git 版本号）。**期数只属于固定栏目 / 日更系列**；单篇文章不许拿章节数、内部版本号充规模（见六条硬禁第 3 条）
- 🔴 **封面标题 ≠ 外标题**：本文锻造的是「外标题」（卖"这篇整体是什么"）；封面主标题是另一层（卖"里面最值钱的那个核心"），走 [cover-styles.md 封面文案四招](cover-styles.md) -- **封面不复述外标题核心关键词**，别让两处一个意思。**blueprint 蓝图闸启用时**，每个外标题候选须当场配好这套封面文案（L1/L2 与 2--4 个可视化事实），组成「标题+封面」配套视觉方案一包交付作者选定（见 [outline.md 步骤 8](outline.md)）。

## 7 步质检（逐条过，不达标就地换）

1. **覆盖性**：只读竖杠后这一句，能说出整篇讲什么、给了什么吗？说不出 → 它写的是局部发现，重写
2. **关键词**：竖杠后最前面是不是一个读者真会搜的专名？是抽象组合词 → 换掉
3. **反差自检**：有没有「你以为…其实不…」的影子（含「不是他写的」「多半不是」这类否定揭穿）？有 → 改回正面陈述
4. **编号自检**：有没有章 / 期 / 版本号这类内部切分数？有 → 换成读者一眼懂的规模量，或直接删
5. **一遍即懂**：读一遍就知道在说什么？要读两遍 → 改
6. **长度**：超 20 / 30 字 → 砍
7. **人味**：像人起的还是机器生成的？

## 🔴 定稿标题后：同时锻造「封面五项」

外标题定下来后**不要停** -- 封面上的字是另一套文案，必须在这一步一并定死，
不能留到生图时让模型现挑。产物写进 `article-meta.yaml:lead`：

| 字段 | 是什么 | 硬约束 |
|---|---|---|
| `lead.line1` | 封面 **L1 主标题** | **4--7 个汉字位**（数字/半角按 0.5 折算），硬上限 8 |
| `lead.line2` | 封面 **L2 副标题** | **≤ 12 个汉字位**，单行 |
| `lead.accent` | L2 里染主题色的**落点词** | **2--5 个字**，且必须是 line2 的**结尾**子串 |
| `lead.tag1` | 底部品牌胶囊标签 1 | **≤ 4 个汉字位**，必填 |
| `lead.tag2` | 底部品牌胶囊标签 2 | **≤ 4 个汉字位**，必填，且不得与 tag1 相同 |

`lead.subtitle` 是文章导读副标题，只允许字符串，**不进入封面**。封面编译器只认上表五项；
缺任一项、字段错位或超长都直接停止，不允许生图模型代填。

**上限为什么是硬的**：L1 要占画布高 12%--14% 才能成为视觉主体，反推左区
只放得下约 8 个汉字。**超一个字，模型就只能缩字号**，封面规范再严也压不住 --
第 81 篇封面翻车正是这么来的（详见 `cover-styles.md` 的字号层级节）。

**下限没有硬约束，别为了凑字数注水**：作者原话 --
「四个字也挺好……如果有一些文章，四个字五个字能说清楚的，我觉得也够了，没关系。」
第 80 篇「生意变了」正是四字范例。**能四个字说清就四个字**，
6--7 字是舒适上沿，8 字是不可越的硬顶。

**两个封面标签的例子**：

```yaml
lead:
  line1: "额度重置"
  line2: "排进一张日历"
  accent: "一张日历"
  tag1: "额度"
  tag2: "预警"
```

**落点词怎么挑**：选那句话的**语义落点**，也就是读者读完最该记住的动作或结论。
好例：「从抢年轻人，到**抢老人**」/「两端装上，一直**看得见**」/「排进**一张日历**」。
坏例：染开头、染虚词、染满整行。**L1 一个字都不染**。

**和外标题的关系**：外标题是给列表页和朋友圈看的完整句，封面文案是给缩略图看的
短句 -- **不要把外标题原样塞进封面**。外标题可以长、可以带「分享 |」前缀；封面必须短、
必须一眼读完。

输出时把五项一起给出，例如：

```
封面五项（已回填 article-meta.yaml:lead）
  L1  54 次额度重置        （7 字位 ✓）
  L2  排进一张日历          （6 字位 ✓）
  染  一张日历              （4 字，line2 结尾 ✓）
  标签 额度 / 预警           （各 ≤ 4 字位，且不重复 ✓）
```

## 输出格式

直接在对话中输出，不写文件、不生成时间戳：

```
分类标签：洞察（outward_category: insight） -- 已回填 article-meta.yaml

[推荐] 1. 洞察 | 标题文本
       -- 一句话说明

2. 洞察 | 标题文本
   -- 一句话说明
...
```

（首行先亮标签+已回填 meta，5 个候选统一带 `标签 | ` 前缀。）用户要更多就继续迭代生成候选。
