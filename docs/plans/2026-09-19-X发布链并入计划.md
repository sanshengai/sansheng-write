## 目标与验收口径

- **目标**：公众号定稿 → 一条命令出 X 文章草稿 → 校验 → 发布 → 回读，整条链在 `scripts/x_article.py` + `references/x-article.md` 内闭环；X 侧的写作规则与资料页规则并入既有 reference，不另立 skill。
- **验收口径**（每一项都要有能被拒绝的反例，与 iron-rules 一致）：
  - 脚本类：`tests/test_x_article.py` 用离线夹具（Markdown 片段 + 假 DOM 块序列）测转换与校验；浏览器链路用第 99 篇做端到端回归（13 图，文本/块类型/空块零差异）。
  - 规则类：每条新规则在 reference 里带一条正例和一条反例；磨稿清单对应勾选项能指回规则编号。

## 第二批 · 写作层（`references/anti-ai-filter.md`、`title.md`、新增 `references/x-caption.md`）

**2.1 `anti-ai-filter.md` 补 7 条**（吸自 x-skills `scrub-rules.md` V3，按 445 条语料校准，与本文件"判罪双判据"互认）：

1. **密度阈值**：AI 味词按密度计分，单元 = 段落；1 个不判罪，≥3 才重写；**不做同义替换**（换词不换结构等于没改）。→ 挂 §2.1 禁用词分级之后。
2. **揭示桥单命中即改**：「结果呢？」「答案是：」「真相是」「别再 X，开始 Y」——不是禁用词是禁用句式。→ §五 AI 句式结构过滤。
3. **表演式真诚单命中即改**：「说实话 / 不瞒你说 / 不受欢迎的观点」开头且后面不跟具体事实。→ §五。
4. **反强制节奏**：不制造长短交替；「简单。有效。完了。」「不 X。不 Y。只 Z。」一词成行禁；碎句 ≤1/段。→ §1.1 句长节奏补边界（现有"破句"条给出上限）。
5. **磨稿不许新增作者没写的 hedge 与告白框**（「让我诚实点说」「我得承认」）。→ §七磨稿清单通用项。
6. **过度矫正三问 + 干净稿只动 1–2 处**：改完问「这句是不是比原句更像 AI / 有没有为改而改 / 删掉改动读起来更顺吗」。→ §七终审门之后新增一关。
7. **三连留一**：排比三连只留第一个「带收据」（有专名/数字/物件）的，空洞可互换的删。→ §五。

验收：磨稿清单新增 4 个勾选项并标规则号；`profile/corpus/反例对照库.md` 各补 1 对（揭示桥 / 表演真诚 / 强制节奏 / 空洞三连）；`contracts.audit_quant_signals` 若能机扫揭示桥与一词成行则加计数（可选）。

**2.2 `title.md` 补 1 条**：具象型填法里，数字要**奇数精度且带指涉**（「三月账单 4,730 美元」不写「5k」；「29 个预装应用」不写「几十个」）。反例：「省了很多钱」。不动六条硬禁。

**2.3 新增 `references/x-caption.md`（主帖说明文字 ≤128 汉字）**：

- 结构：一个由正文主干兑现的判断 + 一个有指涉的具体数字；首句独立成立（信息流只露前两行）；结尾落地，不问「你怎么看」。
- 形态优先「第三人称可核实案例 / 数据点」（x-skills X11/X2），对应 title.md 具象型；说明文字承诺的必须是文章主干交付的（钩子→正文契约）。
- 禁：URL、互动诱饵（点赞转发关注）、揭示桥、≥2 hashtag、严肃题 emoji、以「我」开头的首句。
- 与公众号的分工：公众号导读负责"这篇讲什么"，X 说明负责"为什么现在点开"。
- 出口：`x_article.py --caption-file` 之前由 Agent 按本文件出 3 候选 → 作者盲选；脚本做权重字数与禁项扫描。

## 不吸收清单（避免以后从别处捡回来）

- 官方 API / cookie 发帖：API 免费档发不了文章、改不了资料，bird 发帖会封号。
- 所有「Unpopular opinion / Nobody talks about / 真正的秘密是 / Here's why」式开头：与 title.md 六条硬禁正面冲突。
- 线程结构、🧵 收尾、「2–4 周后重发」（近似重复惩罚）、This-or-That / 填空式互动诱饵。
- 美东/印度时段表、emoji 头 + 3 个 hashtag 模板、Build-in-Public 40% 配额。
- x-skills「禁双连字符 `--`」：与本 skill 铁律「破折号统一 `--`」相反，保留我方。
- social-post 的 FB/IG 留言 DOM 执行层（132 个脚本）、Codex 内置 Chrome 绑定。

## 风险

- X 编辑器 DOM 改版会让占位符替换失效：校验会拒绝发布，不会发坏；修法在 `x-article.md` 坑清单。
- 自动化 Chrome 被人手动关闭会中断运行（09-19 发生过）：1.5 的锁与 receipt 状态能让重跑从建草稿重来，不会留半成品发布。
- 回读依赖登录态页面结构，字段拿不到时记 `null`，不写 0（social-post `null≠0` 规则）。
