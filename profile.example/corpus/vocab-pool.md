# 词汇温度池（原创合成 · 开箱兜底 · 可选）

> **这不是从任何人的作品里抄来的**，全部原创，版权干净，可自由改分发。
>
> **作用**：写作前作为本篇的「词汇配方」参考——**优先**用左列的具体/口语词，避开右列的 AI 默认抽象词。
> 这是**可选**语料：不放本文件也不会报错（`contracts.py` 对缺失优雅降级），只是少一层离线参考。
> **替换**：把你自己的 `vocab-pool.md` 放进 `SANSHENG_WRITE_PROFILE_DIR/corpus/` 覆盖本占位。

---

## 一、抽象名词 → 具体画面

| ❌ AI 默认（抽象） | ✅ 优先（具体） |
|---|---|
| 赋能 / 抓手 / 顶层设计 / 底层逻辑 | 直接说它帮谁做成了什么事 |
| 生态 / 格局 / 范式 / 维度 | 说清是哪几家、哪几步、哪一层 |
| 体验 / 价值 / 意义 | 换成一个可感知的动作或数字（"加载从 3 秒到 0.8 秒"） |

## 二、抽象动词 → 具体动作

| ❌ AI 默认 | ✅ 优先 |
|---|---|
| 提升 / 优化 / 改善 / 推动 | 说清怎么做的（"把七步并成一步"） |
| 打造 / 构建 / 布局 | 换成朴素动词（做 / 搭 / 铺） |
| 助力 / 驱动 / 引领 | 说清具体帮上了什么忙 |

## 三、书面连接词 → 口语过渡（按语境，不强求）

| ❌ 偏书面 | ✅ 偏口语 |
|---|---|
| 此外 / 与此同时 / 综上所述 | 还有 / 顺带 / 说到底 |
| 值得注意的是 | 有意思的是 / 关键在 |
| 然而 / 尽管如此 | 不过 / 话说回来 |

> **用法提醒**：这是「优先」不是「禁用」——右列词服从语义自然，别为了替换硬塞。词汇黑名单的硬约束在 `anti-ai-filter.md §2.1`，本池只作离线参考。想长出自己的词汇偏好，照此格式追加你自己的对照即可。
