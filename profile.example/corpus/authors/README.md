# 怎么自建一份「作者风格手册」

> 这个 skill 的风格路由，靠的是 `<作者名>.compact.md` 这种手册。
> **公开仓不附带任何真人作者的手册** —— 那类手册要从对方受版权的作品里蒸馏，
> 不该由我打包分发给你。这里给的是**方法**，以及一份虚构作者的示例（`example-author.compact.md`）。
>
> 好消息是：你要模仿的作者，本来就该由你自己挑。别人替你挑的，长不出你的声音。

## 为什么这样设计

| | 结果 |
|---|---|
| 送你 12 位名家的手册 | 所有用它的人写出同一种腔调；而且我在替你分发别人的版权衍生物 |
| 教你怎么做手册 | 你模仿你真正喜欢的人；语料留在你自己机器上；版权风险归零 |

## 三步做一份手册

### 1. 攒语料（20-50 篇即可起步）

把你想模仿的作者的公开文章存成 markdown，放进 `corpus/raw/<作者名>/`。
这个目录在 `.gitignore` 里，**不会被提交**。

> ⚠️ 只用于你本机的私人学习用途。别把别人的原文提交到任何公开仓库，也别再分发出去。

### 2. 蒸馏成 compact 手册

把语料丢给 Claude，用这段提示词：

```
读完 corpus/raw/<作者名>/ 下的全部文章，产出一份 ≤500 字的「执行手册」，
帮我在写作时复现这位作者的招式。要求：

1. 只写「这位作者特有的、别人不这么干」的招式，通用写作原则一律不写
2. 每条招式给：动作名 + 一句话怎么做 + 一个我可以照着填的句式骨架
3. 单列一节「他从不做什么」（禁区往往比招式更能定义风格）
4. 单列一节「典型开篇的三种起手式」，各给骨架
5. 节奏参数：平均句长、段落长度、每千字的具体名词/数字密度
6. **不要逐字摘抄原文**。只描述招式，用你自己造的例句演示

输出为 markdown，存成 corpus/authors/<作者名>.compact.md
```

**关键约束**：手册里**不要放原文节选**。只放"招式描述 + 你自己造的例句"。
这既是版权自保，也真的更有用 —— 摘抄会让模型去模仿那几句，而不是学会那个动作。

### 3. 用它

`profile/brand.yaml` 里设 `writing.default_style: <作者名>`，
或者在对话里直接说 `[目标风格：<作者名>]`。
`scripts/prep_writing.py` 会自动把对应手册注入写作上下文。

## 手册长什么样

看 `example-author.compact.md`（虚构作者，纯为演示格式）。

## 常见问题

**Q：我一份手册都不做，能用吗？**
能。会自动注入 `../voice-samples.md`（本项目原创的人味示例集）作兜底，
产出不会是 AI 通稿，但也不会像任何特定的人。这是设计，不是缺陷。

**Q：手册越多越好吗？**
不。3-5 位就够。风格路由是"单选其一"，手册太多只会让选择变难。

**Q：能做"我自己"的手册吗？**
最该做的就是这个。把你过去写得最满意的 20 篇丢进去，蒸馏出的手册
会告诉你一些你没意识到的自己的习惯 —— 有些值得保留，有些该改。
